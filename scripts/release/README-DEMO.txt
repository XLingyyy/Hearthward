Hearthward（归火）Windows Demo 0.1.0

安装
将 Release 中的 Setup.exe 和所有 Setup-*.bin 文件下载到同一文件夹，双击 Setup.exe。
安装完成后运行桌面的 Hearthward Demo。无需 UE、Python、API Key 或额外下载模型，游玩时可离线。
首次需要安装微软 VC++ 运行库时，按安装提示完成。

系统与 AI
Windows 10/11 64 位，支持 DirectX 11/12 的独立显卡。建议 16 GB 以上内存、8 GB 显存，安装目录预留 10 GB。
默认使用中等画质、30 FPS，为本地推理保留 GPU 余量。
默认桌面快捷方式使用 Vulkan GPU AI。首次进入游戏会在本机加载 Qwen3.5 4B，需要等待；回复耗时受硬件影响。
如果驱动不支持 Vulkan 或显存不足，从开始菜单选择 Hearthward Demo (CPU AI)。CPU 回复较慢。
保留两种启动方式；双击安装目录内 Hearthward.exe 也会使用 CPU AI。

操作
新游戏：主菜单点击新游戏，进入自然营地。
WASD 移动；鼠标转动视角；Shift 冲刺；空格跳跃；E 与附近物体交互。
Tab 背包；T 与30米内的弟弟交流；R 营地仓储；B 建造；K 技能。
F6 存档；Esc 暂停/返回。背包窗口暂停，对话窗口继续运行，空白区域可看到场景。
伙伴：X 跟随、Z 等待、C 协助攻击。自然地图尚未布置战斗敌人。
建造：B 选择工作台、床或篝火，移动/转动视角选择位置，Q 旋转，左键确认，右键取消。
工作台：靠近按 E，选择箭矢、绳索、石斧、药膏配方，调整数量并制作。

建议体验路线
1. 在营地活动，打开背包查看补给，到箱子附近按 R 存取物资。
2. 靠近树木、石头、灌木按 E，保持5秒完成采集；移动或跳跃可中断。
3. 按 T 对弟弟说“帮我采集两份木材带回营地。”，核对任务卡后确认，让弟弟执行并交付。
4. 采集材料，B 建造工作台；靠近 E 制作绳索和箭矢。可再建床休息、建篝火烤肉。
5. F6 保存，返回主菜单后继续游戏，检查营地和库存恢复。

Demo 边界
本版是可试玩预览，包含自然营地、采集建造、制作、双角色和本地 AI。
完整剧情、自然地图敌人和正式战斗关卡尚未完成。武器手部挂接、地形与植被细节仍有瑕疵。
AI 的自由表达可能触发澄清或拒绝；只有玩家确认后的有效任务会执行。
请勿将 Source code.zip 当作游戏安装包。问题反馈：https://github.com/XLingyyy/Hearthward/issues
