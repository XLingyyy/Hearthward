Hearthward（归火）Windows Demo — 0.2.0-preview.20261006.1

运行
完整解压发布包到可写目录，双击“启动游戏.cmd”。请保留整个Windows目录，不能只复制exe。
无需安装UE、Python或下载AI模型。默认入口使用Vulkan GPU AI；遇到显卡兼容问题可使用“启动游戏_CPU.cmd”。CPU推理较慢。
若提示缺少VC运行库，运行Engine/Extras/Redist/en-us下随包安装程序。
本包是开发预览，测试范围与已知问题见同目录RELEASE-NOTES.txt；源码状态见BUILD-INFO.json。

开场路线
新游戏从山地石堡的双床卧室开始。靠近遗物包按E拿护符，按X叫弟弟跟随。
出门沿回廊右行，下楼梯进入庭院。穿过有灯笼的城墙侧门，前往任务指引的后巷撤离点，按E撤离。
进入营地后按J查看后续目标。主堡和六栋石屋提供外观，目前没有可探索的完整内室。

主要操作
WASD移动；鼠标转动视角；Shift冲刺；空格跳跃；E交互或在符合条件时攀越。
X弟弟跟随，Z等待；Tab背包，T交流，R营地仓储，B建造，K技能，J任务。
M局部地图，可切到世界地图；F6存档；Esc暂停/返回。
背包可拖放装备。1药品、2食物、3弓箭、4投掷；选中弓箭后按住左键拉弓、松开射击。
建造时Q旋转，左键确认，右键取消。靠近工作台按E制作。

建议试玩
1. 与弟弟走完卧室、回廊、庭院和夜袭撤离，进入营地。
2. 查看背包、任务、地图和设置，尝试采集、仓储、建造与制作。
3. 向弟弟提出明确的短任务，核对任务卡后确认执行。自由表达可能需要澄清或被拒绝。
4. F6手动保存，退出游戏后重新启动并继续，核对进度。

配置与限制
Windows 10/11 64位，DX12独立显卡。本机验证硬件为RTX4060 Laptop 8GB；其他硬件兼容性尚未全面验证。
建议至少16GB内存，关闭占用较高的应用，为本地模型和游戏留出内存与显存。
画质和帧率可在设置中调整；推理响应速度受硬件和当前场景负载影响。
本版保留现有战斗、营地、伙伴及存档系统。精细美术、完整夜袭过场、完整游戏节奏和第二台机器验收仍在开发中。
旧存档继续使用游戏内迁移、进度隔离和备份机制；首次体验本次开场建议选择新游戏。
