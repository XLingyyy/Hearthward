# UI 组件与布局编辑

在 Development 游戏或独立预览中按 **F10** 进入布局编辑。HUD 也可直接进入；编辑期间世界暂停，游戏按钮不执行动作。退出后恢复该页面原本的暂停和输入方式。

| 操作 | 输入 |
|---|---|
| 选择、移动组件组 | 鼠标左键拖动 |
| 单独选择纸张、图标、文字、线条或按钮 | 按住 Alt 点击，再拖动 |
| 缩放选中组件 | 拖动右下角青色方块 |
| 精确移动 | 方向键 1 单位，Shift + 方向键 10 单位 |
| 拖动对齐至 10 单位 | 拖动时按住 Shift |
| 遍历组件组（含已隐藏项） | Tab |
| 隐藏／显示选中项 | Delete |
| 撤销最近一次编辑 | Ctrl + Z，最多 32 步 |
| 恢复当前页默认布局 | Home，可撤销 |
| 前／后一页 | Page Up / Page Down |
| 保存全部页面布局 | Ctrl + S |
| 退出编辑 | F10；独立游戏也可 Esc |

退出编辑保留当前会话的改动；**Ctrl + S 才写入磁盘**。PIE 的 Esc 可能被 UE 用来停止运行，因此优先使用 F10。Shipping 禁用编辑入口及写入能力，仍读取已经保存的布局。

## 文件职责

- `interface.json`：元素类型、字体、文字／状态绑定、图集、UV、颜色、按钮命令、默认静态元素。每个静态元素有稳定 `layoutId`。
- `layout.json`：每页的组件组、默认矩形、当前矩形、显示状态及单独图层覆盖。可直接版本管理，也可通过 F10 编辑保存。
- `Art/*-scene.png`：无 UI 结构的场景。背包角色另用透明 PNG，任务插画另用图片组件。地图地形独立于背景。
- `Art/leather-panel.png`：独立透明皮革纸张，九宫格绘制。分隔线、徽记、预览插画、文字和交互不在这张纹理里。
- `Resources/Data/gameplay.json`：物品、技能、任务等真实玩法内容，布局编辑不改动这些内容或游戏存档。

## 组件配置

```json
{
  "id": "pause.menu",
  "base": [587, 50, 455, 840],
  "rect": [587, 50, 455, 840],
  "visible": true,
  "asset": "leatherPanel",
  "capture": [587, 50, 455, 840]
}
```

矩形依次为 `x, y, width, height`，基于 1672 × 941 设计画布。窗口缩放和留边由根画布处理。`base` 是默认布局空间，`rect` 是实际摆放空间。移动和缩放组时，其纸张、文字、图标、点击区域同步变换。默认锚定在 `interface.json` 内先解析，例如 HUD 方位栏的屏幕中心锚点。

静态元素用 `component` 显式指定所属组。数据生成的行、格子、属性等由 `capture` 区域分配到对应容器；多个区域覆盖同一点时，后声明者优先。仓储类别及地图地形、迷雾和标记显式归属其容器。扩展动态内容时可直接设置元素 `Component`，避免区域歧义。

`asset` 是可选的组件底面。每个底面自身也是可选图层，ID 为 `surface:<组件ID>`。Alt 点击或调用 `SetComponentVisible` 可只隐藏纸张、保留内容；普通选择组件组可整体隐藏。无底面组件也能容纳控件，例如 HUD、装备槽和地图。

单独图层的 `overrides` 以其 `layoutId` 为键，矩形仍保存在父组件默认坐标系中，故后续移动父组件不会破坏子元素关系。动态元素的编辑地址对应默认位置和类型的模板槽位，不保存当前文字、数量或物品状态。需要跨模板变化的独立地址时，应给元素显式 `LayoutId`。

## 扩展与验证入口

新增一个可拖动面板：在 `layout.json` 的目标页添加唯一 ID 的组件，可引用已有皮革底面；在 `interface.json` 添加控件并设置 `component`。调整字样、图标素材、命令与字体仍通过 `interface.json`；F10 编辑器负责几何布局和可见性，不是 UMG Widget Blueprint Designer。

九宫格的 `margin` 为源纹理切片比例，`brushSize` 控制设计画布中的边缘厚度；纹理实际分辨率不会把边缘撑大。普通图片保持独立 UV，可替换素材而不重写交互代码。

蓝图／UE Python 可调用 `SetComponentRect`、`SetComponentVisible`、`SaveLayout`、`ReloadLayout`。`DescribeLayout` 返回实际矩形、父组件、可见性及动作；`ActionAt` 使用游戏真实点击命中路径。地图裁剪、右键坐标换算和原生中文输入框均使用同一组件变换。

存档页只创建 `save.sheet`，设置页只创建 `settings.sheet`；暂停页的 `pause.menu`、`pause.info` 不再出现在它们的背景里。
