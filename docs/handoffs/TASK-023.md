## 使用与实现

- 靠近022建好的工作台，HUD出现E使用工作台；按E优先进入制作页面。选配方、−/+调批数、F或按钮即时制作，返回按钮/Esc关闭；PIE可用返回按钮避开编辑器Esc停止Play。
- 普通箭矢、绳索配方默认掌握；实际扣除背包木材，产出直接进入背包。每批原型为1木材→4箭矢、1木材→1绳索。玩法JSON新增craftingRecipes及crafting；访问260cm、上限99批均PROTOTYPE_ONLY，R13/R14保持OPEN。
- 不预留、不锁定材料、不等待五秒。022建造仍为五秒；本单不扩展熔炼、烹饪、燃料、生产、稀有蓝图或装备制作。现有耐久按物品类型保存，装备制作应先确定实例耐久语义。
- 材料与产出在库存副本中整体校验，以扣料后的最终重量判断容量，全部成功才替换原库存并发布一次变更。任何缺料、容量或计数失败不产生部分结果。
- 制作执行重新校验稳定工作台ID、实体存活、距离、视线、人物健康/战斗/持续动作和时间线。菜单默认暂停，但可即时制作；离开、隔墙、施工或回档后旧请求不能结算。
- 使用现有库存及craft事件快照，无新增存档格式。读档关闭制作页面并废止epoch；恢复物品数量与事件，不重放制造。制作结算期间沿用Building的Settling保护，库存事件回调不能重入制作或在事件尚未完成时保存。
- 制作页的配方面板、详情面板、操作区是3个可独立移动/缩放/隐藏的组件组。动态元素有稳定ID；加入现有F10布局编辑。目前13页56组，背景只含场景，页面纸张/按钮独立。
