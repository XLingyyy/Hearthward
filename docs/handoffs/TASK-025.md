## 当前实现

- AI拥有可快照的认知结构：玩家陈述/偏好/文字约定/结构化采集限制、最后亲见营地库存/活动时间、尚未完成的澄清对话。玩家记录可编辑/撤销，来源不升级为事实；模型没有写记忆或库存的权限。
- 字符片段相关性检索旧记录，文字约定持续进入上下文。回忆答复引用现存记录，没有匹配则明确告知；原始交流日志保留存档兼容，不会把已撤销记录从历史日志重新注入。当前使用词项检索，未引入Embedding或自动总结。
- 指定物品的采集限制由UE在接受新任务前强制检查；原始模型候选保留，最终实际意图另行记录。普通文字约定仅作交流参考，不能提供同等执行保证。
- 到营观察复用执行器的平面距离及高度判断；离营冻结旧观察，返回后更新。库存查询以目录驱动的只读inventory意图接入，数值答复由UE按当前/上次亲见快照生成，避免自由台词虚构数字。
- 待澄清保存完整原话与问题，当前补充能组成真实采集委托；闲聊/库存查询不会自动执行旧提议。超预算要求重述，不默默截断限制。
- 快照新增反射字段，旧档缺字段默认为空认知，原始日志保持；认知与库存、时间和命令同边界恢复。编辑/撤销废止进行中的模型回复，已经接受的委托继续，需要单独取消。

## 操作

新游戏 → 弟弟30米内T → “记忆与约定”。填原话，选陈述/偏好/文字约定后点击“记下这条”或Enter；左侧选择记录，修改保存或撤销。需要强制禁止采集时选择“采集限制”，点击物品行切换目标后保存；默认目标为木材。滚轮浏览，新增按钮清空选择。面板支持F10独立编辑，复用现有皮革素材，无烘焙新控件。

对话输入“帮我采些木材带回仓库”，待弟弟询问数量后输入“三份”。库存问题可直接问“营地还有多少木材”。待澄清时右上角可结束这次澄清，不取消已执行委托。

## 边界与后续研究结论

025交付认知/记忆闭环；当前语言执行仍为安全采集，另提供只读库存查询。制作、建造、修理未接NPC执行；不引入新的营地生产规则、危险感知或自主生活调度。R18/R20/R21仍有未决内容。

长期记录由玩家显式管理；每条120字、64条记录（含撤销记录）、4条有效文字约定；检索另取最多3条相关记录。澄清4轮/800字属于原型上下文预算。模型实测忽略过自由文字约定，因此强制限制采用显式物品选择；任意自然语言约定仍可能被误解。回忆采用词项匹配，语义改写可能查不到，采集限制在管理页查看。

4B模型仍可能重复追问或在台词中出现技术措辞；有限场景通过不等于开放表达鲁棒性和角色台词质量已达发行标准。

研究来源与取舍见[ADR](../decisions/ADR-TASK-025-npc-cognition.md)。下一步的工程重点是把真实制作等能力按同样的前置条件/执行结果接口接入，并扩大约束与表达变化评测；不需要先换多Agent框架。

正式Issue/独立评审仍缺项，流程保持Blocked；用户验收待定，Shipping打包和两机验证未执行。
