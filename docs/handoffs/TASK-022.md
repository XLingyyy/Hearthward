# TASK-022｜自由建造、五秒结算与建筑回档

用户授权“继续022，自己提交推送”。本单从 TASK-021 的 `9edf1e43419c6b6583728379e048231f8a653cce` 堆叠，分支 `codex/TASK-022-camp-building`。范围提交 `4c700bb`；实现提交绑定由本目录证据中的 `working-tree-binding.json` 提供。未合并 main，未执行 TASK-004，未代替用户验收。

## 实现

- B 打开独立建造目录，选工作台或篝火后返回游戏；移动及转动视角摆放，Q 每次旋转15度，左键确认，右键取消。独立运行 Esc 也取消；PIE 使用右键避免编辑器 Esc 停止游戏。
- 预览沿地面更新，显示绿/红轮廓；支撑检测覆盖中心及四角，拒绝悬空、明显坡度、建筑叠放、角色/障碍重叠。工作台限营地，野外只允许篝火。
- 五秒使用现有世界时钟与 TimedAction。完成时重检位置和材料，整批扣除背包配方，只发布一次已建事件；移动、跳跃、受伤、取消和切换菜单中断且不扣材料。其他持续动作尚未结束时不能同时施工。
- 建筑为独立运行时 Actor，拥有碰撞及导航障碍；外形用引擎基础形状组成，部件位置/比例、配方、名字、范围都来自 `Resources/Data/gameplay.json`。没有制作新的二进制美术或地图。
- 建造界面的面板与按钮分离，加入现有 F10 布局编辑；12页共53组件组。新增提示也属于可编辑组件。
- 已建建筑的稳定ID、配方ID、位置和旋转进入现有玩法JSON。读取节点之前取消旧施工，销毁未来建筑，再重建节点建筑；不重放材料消耗或完成事件。旧档缺少 `buildings` 字段按零建筑处理，未知配方、重复ID和无效结构在世界变更前拒绝。
- 施工期间保存延后；完成后的建筑和库存位于同一个快照边界。

## 参数与边界

工作台8木材、篝火4木材、营地半径1200cm、预览距离240cm、旋转步长15度均明确为 PROTOTYPE_ONLY。当前木材采集点是真实入口，因此这两项配方可在正常游戏中完成，无需控制台授予石材。R11/R13保持OPEN；此配方不表示已满足“三分钟工作台”的最终节奏。

本单只完成建筑放置与持久化。工作台加工、篝火火焰/休息/睡眠、建筑升级、生产、第二营地设施和正式美术尚未制作。没有拆除返料功能，没有新增正式键位决定。旧存档若材料已入库，可用营地R取出后建造。
