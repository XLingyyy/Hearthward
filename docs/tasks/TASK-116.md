玩家可用真实声源改变局部巡逻位置，形成可观察的潜入空当，敌人不会因此瞬间知道玩家坐标。

**现有基础与增量：**现有感知和警报保留；新增一类诱导声源与调查状态，不要求换掉全部 AI 框架。

## 3. 实现范围与拆解

1. 先实现小石子投掷或一处可操作声源首件；映射既有可消耗物，消耗规则在契约中冻结，禁止免费复制背包道具。
2. 统一声源事件包含位置、时间、强度、类别和事件 ID；调查使用听到的位置，instigator 身份不得变成全知定位。
3. 实现听见、转向、前往、检查、回位有限状态；视觉确认才沿原警报链升级，战斗状态优先。
4. 重复声源只在本次局部遭遇中衰减兴趣/延迟复查，范围和重置明确；射线遮挡/传播近似需可解释且有预算。
