## 3. 实现范围与拆解

1. 映射现有守望者，前段记录其对安全与归乡的态度；不能在故乡未夺回时直接播放胜利结局。
2. 通过实地查看旧号台或归乡通路承接，目标以现场状态而非新刷敌人支撑。
3. 归乡后选择保留纪念陈列或整理为生活区提示，关联一个有限空闲行为，不另建长期反击/巡防经济。
4. 结尾由实际第二营地状态、玩家选择与人物可用性驱动；未完成的原主支线仍可继续。
