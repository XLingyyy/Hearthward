1. 设计观察点、正面掩体路、侧门路线、高处射手、守卫/重兵组合和内侧捷径；复用现有敌人 ID 与巡逻合法范围。

3. 清场后接入维持装置协作，玩家开栓，弟弟汇合；最终成果恢复一个实际可用通路/工作位置。
4. 按观察→准备→战斗→合作→回营反馈组织节奏，目标体验 15—25 分钟仅为设计预算。样板先于天气、生态、装饰扩展。
