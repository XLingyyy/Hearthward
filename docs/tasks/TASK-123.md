**现有基础与增量：**现有工具交付、营地陈列与工作岗位已存在；本单将一名真实人物、一个具体选择和日常结果连起来。

## 3. 实现范围与拆解

1. 由 TASK-112 映射一名现有人物，暂用“工匠”作策划角色名，不创建额外人口。
2. 三段结构：认识他对旧作坊的态度；实地检查旧工作位/工具；选择留在营地生活区或恢复故乡展示位置。
3. 一份物件只能在一个位置显示。选择只影响个人陈列/对白/安全空闲行为，不修改岗位产量或强制迁移劳动力。
4. 完成后人物在不影响真实工作的时段使用/查看对应物件，弟弟只在已知事实下回应；文本先行，录音不是新增阻断。

## 4. 开工前必须冻结的具体项目

- 冻结人物真实 ID、两种结局文字与显示槽位；不暗改既有岗位体系。
- 原工具已交付的旧档采用对应可见事实承接，不补发第二件工具。
