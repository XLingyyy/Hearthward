## 3. 实现范围与拆解

1. 交付一个双人移梁模板，明确两个站位、目标承托区域和可用净空；先做确定性关键帧移动，不做任意刚体搬运。
2. 双方就位后播放同步动作，提交时一次改变障碍位置与导航；完成前不解锁路线。
3. 中途中止时回到安全承托位置，不把重物落在玩家或救援人物身上，不增添压伤系统。
4. 物资型交互若后续启用必须走原库存事务；本单首件只移障，不额外叠加绳索悬吊与高空救援。
