## 1. 玩家体验目标

让一次出门因天气产生不同观察与接近方式，而不是给玩家增加必须维护的生存状态条。

**现有基础与增量：**已有世界时间与昼夜。本单新增一种轻雨，不同时实现薄雾、雪、四季和温度系统。

## 3. 实现范围与拆解

1. 只交付晴天↔轻雨及平滑过渡，室内遮蔽正确；状态由共享世界时钟驱动且可重建。
2. 轻雨对未确认目标的可见/可听条件施加经批准的有限因子，玩家的信息展示与敌人规则一致；已确认战斗不因下雨被清除。
3. 先在粮窖和一段野外路线验证，雨天无独占主线目标；设置降雨视觉强度不改变规则优势。
4. 天气种子/状态/剩余进度由 TASK-131 持久化；暂停、睡眠、读档按同一时间域处理，不用系统墙钟刷新。
