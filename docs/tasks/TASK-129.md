## 1. 玩家体验目标

让玩家通过真实活动留下的有限线索寻找动物，而不是跟随一个永远准确的地图箭头。

**现有基础与增量：**已有动物状态、狩猎、钓鱼与林间猎迹指向近处真实动物。本单增加时间性证据链，不重新增加物种数量。

## 3. 实现范围与拆解

1. 先选两种现有野生动物及一片有界观察区，由实际位置采样生成踪迹；绑定物种、个体 ID、生命代次、地点与世界时间。
2. 踪迹显示新鲜/陈旧和大致方向，不展示不可见个体的实时坐标；动物死亡/刷新后不把旧迹指向新个体。
3. 设置每个体/区域的采样距离、时长与数量上限；远处使用低频更新，不生成全图无界轨迹历史。
4. 获取资源仍经真实追踪、战斗/狩猎和原掉落事务。钓鱼保持现有规则，本单只为后续提供同类真实线索约定。

## 4. 开工前必须冻结的具体项目

- 冻结两物种与采样区、痕迹寿命和预算；先复用现有物种/模型。
- 选择少量持久样本或确定性重建，不允许各客户端墙钟独立推断。
