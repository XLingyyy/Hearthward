## 3. 实现范围与拆解

1. 映射一名现有族人，依据玩家已知的药圃/路线触发对话；未发现地点不直接给精确位置。
2. 共同目标是检查一处旧药圃和一段可返回的安全路线，复用真实采集/地形条件；不要求永久耗尽或重置资源。
3. 结果选择将一份说明记录放在营地或故乡生活区，或保留一处纪念性陈列；不改资源再生周期与产量。
4. 完成后增加有限的空闲照看/整理行为与事实回应；与岗位、睡眠和其他故事事件错峰，避免重复广播。
