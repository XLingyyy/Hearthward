1. 从唯一战斗结果事件驱动命中特效、受击方向、音频与镜头，标记动作/目标/时间线身份；无结果时不制造命中反馈。

3. 若采用命中停顿，只作用于明确表现域；不得暂停世界计时、救援、模型请求或重复碰撞。
4. 提供镜头震动和强闪烁的可关闭选项，关闭后保留声音、姿态与方向提示；不改现有键位。
