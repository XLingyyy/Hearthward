## 3. 实现范围与拆解

1. 首版只交付三类陈列对象与六个预设安全槽位，覆盖两营地；实际对象优先来自本轮人物线，数量为制作范围，不是资源奖励。
2. 使用放置预览、确认、撤回/移动流程；每个真实物件或纪念事实只对应一个拥有者和可用展示实例。
3. 槽位避开床、工作点、救援路线和梯门，不能移动关键设施或改变人口/产量。
4. 按 CampID + SlotID + Item/FactID 持久化；等级外观重建、第二营地解锁、旧档迁移后仍保持正确归属。
