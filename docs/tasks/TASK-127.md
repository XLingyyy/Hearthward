1. 建立室外探索、室内、战斗、回营四类混音状态与可逆过渡，沿真实游戏状态触发。
2. 危险提示/交互结果优先于环境循环；处理对白避让、火风水层次及门口过渡，固定人声未录制时用文本方案验收可做部分。
