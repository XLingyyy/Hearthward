## 1. 玩家体验目标

让熄灭/遮挡一处指定灯具改变局部被发现条件，玩家能理解并利用明暗，不只是画面变黑。

**现有基础与增量：**已有灯具、光照和感知。本单只处理一个院落与有限灯具，不引入全地图实时光照测量。

## 3. 实现范围与拆解

1. 对选定灯具建立稳定 ID、开关状态、影响区域与可交互提示；只接入合法灯具白名单。
2. 采用可查询的局部暴露因子，纳入原发现/警报规则；亮暗仅影响未确认目标，不能清除已经看见的敌人事实。
3. 定义日间、室内、遮挡、玩家手持光源等边界，避免白天熄一盏灯获得夜间隐身。
4. 保存灯具可逆状态；加载、流送和再次点亮同步画面、提示及感知，不因重建 Actor 丢失。

## 4. 开工前必须冻结的具体项目

- 冻结局部暴露公式与支持的灯具类型；不把画面亮度直接当权威世界数据。
- 交互耗时、重新点亮规则和持久状态默认值须记录。
