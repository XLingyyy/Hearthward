## 1. 玩家体验目标

让短刃、石斧/钝器、长枪在距离、时机和风险上各有适用场景，消除持续后退轻击的万能解法。

**现有基础与增量：**已有轻重击、闪避、格挡、锁定、耐力、独立耐久和移动攻击；本单提升组合价值，不重新添加这些功能。

## 3. 实现范围与拆解

1. 先映射三类实际装备和现有 Move 参数，建立攻击前摇、有效段、后摇、移动能力、耐力与有效距离对照。
2. 短刃强调短窗口撤出；斧/钝器强调承诺式重击；长枪强调距离控制。若新增打断/防御破绽，必须定义触发、免疫与退出，不引入整套新战斗资源条。
3. 保持下肢移动与上半身攻击分层，逐件核对可视刃部、实际扫掠、目标去重和斜坡方向。
4. 制作三组固定对手/空间夹具，记录输入与结果；重击后摇和耐力调优不得用放大伤害掩盖操作问题。
