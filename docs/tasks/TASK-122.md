## 3. 实现范围与拆解

1. 提供受监视的正门与可观察的侧路，通过声音/局部明暗制造空当；玩家可选择战斗，但不强迫清空全区才完成此支线目标。
2. 内室布置一个可理解的空间障碍与物件目标，安全区使用第二种协作；必要时提供单人绕路。
3. 完成后从内部打开返回出口；所有新增物件用唯一 ID，与旧粮窖食物事实明确分开。
4. 交付 15—25 分钟设计预算内的完整段落，控制文字篇幅与路程，避免每个角落都塞同类收集。
