# TASK-051 动物实机接入

来源为2026-10-01用户的三个顺序任务。阶段一导入当前14套SK和303段配套动作；阶段二将物种动作表接到自然行为、兄弟感知与实际伤害；阶段三在独立本地地图提供每种一只的封闭观察区和水池。

演示使用现有主角、弟弟及正常移动/攻击输入，提供观察、弟弟接近、致命伤害和重置快捷操作。动物骨段、动作时长和足端轨迹沿当前制作成果；状态切换短时间混合，奔跑速率与实际速度匹配。陆生动物随机交替移动与本物种自然动作，鱼类交替缓游与觅食/悬停。感知触发逃离，离开威胁后逐步恢复；死亡动作播放完保持末姿态，不自动站起。
