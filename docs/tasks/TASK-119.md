## 1. 玩家体验目标

让弟弟实际走到装置旁维持绞盘，玩家从另一侧完成操作，双方随后安全汇合；不再只是读分工指引。

**现有基础与增量：**已有跟随、等待、委托、手动任务卡与四类分工说明；本单新增现场协作的真实空间状态。

## 3. 实现范围与拆解

1. 统一 Idle→Approaching→Ready→Holding→Committed/Cancelled 协作状态及目标/参与者/时间线身份；单个弟弟仅参与一个动作。
2. 通过明确目标交互进入、反馈已就位、维持和松手。模型可选地转成同一候选，但离线/失败时确定性入口完整可用。
3. 玩家穿越装置后从内侧解除门栓；释放时检查安全体积，禁止关门夹人。弟弟重新加入原跟随/等待状态。
4. 保存只持久化已完成的环境结果；进行中协作安全取消或恢复为可重试状态。提供较慢但可完成的单人替代路线。

## 4. 开工前必须冻结的具体项目

- 冻结装置首件、取消时的安全门态和单人替代路线。
- 协作只在安全现场；危险自动撤销，禁止解释为新增战术潜入委托。
