# TASK-030｜Demo 采集与营地交互

2026-09-23 用户授权。UE5.8.2，现有自然营地与角色视觉，单人 Windows demo。

核心循环：营地附近采木/石/药草 → 建工作台 → 做绳索/箭矢/石斧/药膏 → 建床、休息 → 存档继续。沿用 E 五秒动作，移动/跳跃/受伤中断，B 建造，R 仓储，T 伙伴。

最小配方：工作台8木；篝火4木4石；床6木2绳；绳索1木→1，箭矢1木→4，石斧2木3石→1，药膏2草药→1；篝火1鲜肉1木→1烤肉。床休息消耗10饱食、恢复30生命/全部耐力，不跳过世界时间。数值只作为demo版本。

资产：复用已导入树/岩/灌木，复用现有Tripo木桌作工作台、绳网木床作床、木箱作营地仓储、现有篝火模型作烹饪设施；不改主地图二进制。专用工匠台、采集音效及躺卧动画列为缺项；石斧已有源模型，持握挂接本demo未实现，不阻塞现有站立交互闭环。

验收：材料和满载原子性、中断、耗尽、床的饱食门槛、建造及跨世界存档恢复；真实场景键鼠试玩和短录像。保留旧AI战斗历史在TASK-029/internal-history。
