## 1. 玩家体验目标

让守卫、射手、重兵在组合中逼出不同应对，并用现有驻军中的一人提供可记忆的精英战。

**现有基础与增量：**已有驻军、巡逻、射手前摇和重兵。精英从 80 名基础驻军中选一个真实 ID，不另加胜利分母。

## 3. 实现范围与拆解

1. 守卫负责接近施压；射手维持射线并在丢失视野时合理调整；重兵保留明显预兆与可利用的攻击后空隙。
2. 为一个既有重兵配置一招额外行为和一段反制窗口，优先复用骨架和动作；不使用单纯加血作为全部差异。
3. 增加有限攻击协调/间距策略，避免重叠围殴和无限排队；仅局部遭遇运行，不做长期自适应军队。
4. 三组固定遭遇复用实际角色与合法地形，明确视野遮挡、追击范围、回位和永久死亡行为。
