# TASK-018｜玩家采集与入库闭环

来源为当前GDD第5.3、6.1、7.8—7.9、13.4节。用户授权Agent自行拆解、实现、验证、提交推送；任务路径见JSON。正式流程因Issue、独立评审及prototype设计审批缺项保留Blocked。

实现：为已有单一伙伴夹具的资源点和营地安装玩家交互组件。E使用011距离/五秒计时，成功后以008/010唯一转移接口结算；017存档菜单和016快照直接覆盖同一资源、背包及仓储。不改变存档格式。

原型边界：每次采1木材、150cm、五秒采集/入库、营地整批存入随身木材只作为PROTOTYPE_ONLY集成策略。现有16木材夹具不增加新授予入口，不自动补货。R03/R13/R14/R19/R23保持OPEN。

工程接口增量：InteractionTarget新增虚函数GetInteractionPrompt与CompleteInteraction；默认完成仍广播原OnInteractionReady，不破坏已有消费者。Interaction暴露只读最近可用目标和完成文本，目标选择与执行复用同一距离规则；存档恢复设Idle后旧文本不可见。ResourceInteraction仅在显式非Shipping初始化后启用。

验收覆盖：真实数量守恒、一次结算、满载/耗尽/空背包失败、移动/伤害/暂停/目标销毁、伙伴争用、交互中存档拒绝/回档取消、两轮PIE磁盘恢复、实键与可读性录像。
