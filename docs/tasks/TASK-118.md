## 3. 实现范围与拆解

1. 先交付内侧门栓、放下短梯、可移障碍三种受控模板；首轮作坊只用其中两种，剩余随粮窖验证。
2. 稳定 ID 关联碰撞、导航连接、交互点与地图已知信息；门、梯、障碍仅允许白名单状态，不做任意物理破坏。
3. 只从合法一侧触发，动作完成后一次提交；取消不扣材料、不提前开路。
4. 留安全落点与反向退路，检查弟弟和被救者净空；梯子采用限定登降路径，不扩展成全地形攀爬系统。
