## 执行顺序

默认单Agent按084→103顺序处理。编号是任务顺序，依赖字段是真实产物前置；可并行的仅为明确无文件/资产冲突的工作。094资产盘点可在084后提前做，不能在净空/样板未冻结前批量改碰撞。

阶段交付门槛：G0=084连续基线和真实路线清单；G1=085—093玩法/UI/路线灰盒与营地链路可用；G2=094—099已批准关键资产/声音实际接入；G3=100—101完整工程流程与存档输入回归；G4=102同版联合性能；G5=103候选/独立机器/真人/实际发布分项结论。每个G的产物和未过门槛单列，不把G1当十小时游戏验收。

## 本批新增计划的边界

材料追踪为一个显式配方+批数的会话暂态；Load清空，不加Save字段。导航仅补关键入口/途经点，不做全地图自动路线。回营摘要只读已有事实回执，缺来源就显示当前状态。岗位动画不计产量，夜袭火烟只做有限表现。这些是本批建议的具体实施边界，随Owner派发确认，不是已实现的新功能。

个人自动跨资源点、队伍采够指定总量自动停产、任意任务队列不在本批。固定人声沿原决定暂缓。联机、两营地运输、好感数值门槛、首版外战争与整城室内继续不做。
