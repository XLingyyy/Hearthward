## 灯具
白名单灯具维护实例开关状态与局部暴露区域。日间、室内、遮挡、手持光源边界必须定义。熄灯影响发现条件，不抹除已知敌情。灯光、检测、交互和存档使用同一实例状态。

## 轻雨
只做一种轻雨。晴雨过渡由世界时钟驱动；暂停/睡眠/恢复策略一处定义。视觉画质不改变感知规则。对玩家可用信息与敵人检测采用同一批准方案，不造成单方面失明。不追加温度/疾病/食物腐败。
