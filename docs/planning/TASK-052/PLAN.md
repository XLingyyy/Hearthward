## 2. D1｜唯一时间、日期与昼夜

继续使用既有WorldClock：正常模拟`A+=Δ秒，W+=Δ秒`；暂停、加载过渡、恢复过程冻结；睡眠／篝火只推进W；旅行本身不增加A/W。短动作、恢复、倒地、警戒、自动保存仍按A，生产、饥饿、成熟和周期按W。

**新增批准项**：新进度从第1日20:00开始，符合现有夜袭序章；初始日期和分钟M0随档保存。日出06:00、日落18:00，各以该时刻为中心进行30游戏分钟平滑光照过渡，沿用fix1／fix2的夜间可读性。昼夜、HUD、潜入明暗和已有生态时段规则统一读取`(M0+W)%1440`。序章事件不改写W、不强制拨到白天。旧档M0=0，保留原有日期显示基准；首次升级会按保存时刻恢复正确昼夜。

累计周期仍按W计，显示第几日使用`InitialDay+floor((M0+W)/1440)`，不将显示跨午夜误认为已过去完整一天。标题页、动物观察地图不接入玩家进度的时间／生产循环。

## 3. D2｜睡眠与篝火入口

床保留既有“就座休息”实玩恢复，另有明确“睡眠8小时”入口；后者复用营地设施睡眠能力。**新增批准项**：已建篝火提供等待1／4／8游戏小时，分别推进60／240／480分钟，与烹饪分开显示；没有自动烹饪、自动领料或用餐。

发起时要求有效设施、真实交互距离、当前epoch，双方未倒地／死亡／交战，且无用药、扶起、建造、处决、钓鱼、牵引等短动作或未提交事务。独立采集／护送等进行中的伙伴委托需先由玩家取消或等待完成；睡眠不假称这些任务已完成。严重饥饿允许请求，按实际最早失败点停止。

跳时不增加A，不补生命／耐力／药品／倒地／警戒秒数。普通族人按既有岗位劳动，兄弟不计劳动；材料、饲料、空栏和口粮全部来自真实领域状态。反馈区分拒绝、完整推进及在失败点终止，并显示实际经过时间。

## 4. D3｜事件结算与事务边界

WorldClock协调已有Survival、Camp、Nature和Campaign，不再让某个领域独立推动游戏日期。领域Calendar可保留为快照和结算游标，但只能与权威W同步，恢复时校验一致。

先找本区间最早的生存失败／批次完成／资源到期／成长／繁殖／刷新边界，到该时间点结算。生存预演和实际提交共享技能、状态和倍率；失败之后的产出不提交。到目标恰好等于due时处理到期状态，不依赖再过一帧。

同一时刻按043顺序：已生效动作与伤害→生存失败判断→按046既有优先序结算生产及生态／刷新→区域和任务结果→可见回执→保存安全检查。保留已有库存权威入口和批次状态；不复制第二份库存或生产账本。跳时同步事务期间拒绝重入、保存和模型世界动作，结算完成后才开放输入及通知。

一次跨多日必须与分段推进等价；成熟作物等待收获，缺料等待补给，满栏不累计后代，跳过周期不发无人采集／击杀的收益。遇到技术拒绝，在首次提交前拒绝请求；真实生存失败保留到失败点的合法状态，回档统一撤销。

## 5. D4｜持久资源身份和刷新代次

复用Camp Sources、Nature Points／Slots和Campaign Enemy身份。自然地图旧静态点的稳定键继续保留，048点位GUID及Key随档恢复；流送发现仅重建交互引用。旧静态点当前以Actor／组件／实例及位置组成键，本轮不改地图或实例排序；其流送稳定性需由TM09实际验证，发现身份漂移后再处理已确认问题。

资源按已批准白名单：完全耗尽才登记`due=W+refresh_minutes`，部分采集不计时。到期恢复一份容量；建筑／栏舍阻塞保留原due，解除后恢复一次，无周期欠账。正常采集和岗位采集读取同一Remaining。注册点位不改写已经存在的due，也不随读档重新起算。

野外人类敌人在下一个全局四日边界恢复一个新代次；故乡驻军及增援不复活，旗帜、清敌和胜利不回退。跨多周期只对已清除代次转换一次，不叠加活敌、不回满未清除敌人、不发经验／掉落。049救援等待区、可见性和放置保护保留，受阻记录pending，后续安全解除才物化。

野生动物仍沿048物种周期，保留稳定slot及当前个体／代次；同一代次击晕／击杀结算一次。幼体、家畜和作物不参与野外重复刷新。地面掉落和唯一奖励沿现有持久规则，不增加静默清理。

## 6. D5｜旅行与恢复入口

正常站点旅行免费零跳时。发起时固定参与集合：玩家、与任一兄弟本次交战的活敌，以及交战弟弟；倒地弟弟随行但保留120秒窗口剩余量。未交战弟弟留守、生产或独立任务／跟随按既有导航继续。

复用049的流送准备和Loading入口，先验证玩家和必随弟弟的全部落点，再提交位置、中断的短动作和指定敌血。参战且未清除活敌回自身最大生命；盔甲、异常、警戒、已清除／击晕、奖励、旗帜和胜利保持。任何必随落点失败或提交前已真死亡则不提交旅行。

加载期间A/W冻结，避免读图消耗倒地／警戒时间。落地后重查危险，倒地不能立即保存，自动档只保留一个待安全请求。恢复直接安装完整快照并生成新epoch，取消旧路径／模型结果，不经前进接口重演周期。
