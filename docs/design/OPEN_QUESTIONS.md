# 未定规则登记｜沿用 GDD v0.3 的 R01—R25

来源：GDD v0.3第17章（原文第47—51页）。以下标题与待补内容来自原件，不是工程团队的新决定。
所有条目初始状态 **OPEN**；没有任何批准记录。本工作流只规定如何处理它们。

设计负责人逐项创建DSGN记录，真人审批后在CURRENT中链接并更新状态。
不以“任务能编译”“夹具已设默认值”关闭R项。任务可在不涉及未知规则的子范围继续。

## 与开工的关系

R01—R05优先处理；其他R项按依赖决定具体任务是否Ready，不阻塞不相关工作。
涉及最终结算的完整模块不能以“只缺数字”为由放行；独立机制可以使用经批准的测试夹具。
