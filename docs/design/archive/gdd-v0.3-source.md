## 01  项目定位与体验支柱

约十小时的首版：从夜袭逃亡，到夺回故乡并使用第二营地。

依据：v0.2 第 1 章；Q001—008、Q151、Q160、Q270

### 1.1 游戏定义

单人、第三人称、开放世界生存冒险。玩家扮演遭夜袭后流亡的部族首领，在丛林建立隐蔽营地，组织族人生产，与亲弟弟共同采集、生活、探索、潜入和战斗。通过争取装备、解救族人与夺取区域，收复故乡。

### 1.2 首版终点与完整游戏方向

首版包含夜袭、发展、故乡夺回和第二营地使用，不包含反击敌方腹地、部族战斗小队与最终投降。后者作为完整游戏方向保留，不计入首版十小时验收。首版通关后保留世界，允许继续经营和探索。

| 体验组成 | 目标比例 | 主要活动 |
| --- | --- | --- |
| 营地生活 | 30% | 经营分工、建造、休息、进食及日常互动。 |
| 资源获取 | 30% | 采集、狩猎、垂钓、种植、养殖、采矿与加工。 |
| 探索与战斗 | 40% | 野外兴趣点、潜入、救援、搜集战利品与夺回。 |

### 1.3 创作与体验目标

项目兼用于 C++、Agent、AI、UE5 与游戏设计能力训练及个人作品集。本文仅规定内容、玩法、数值与可见交互，不展开技术实施。弟弟是唯一具有持续自由交流、知识记忆与目标委托的深度伙伴；敌人与普通族人仍有各自基本行为。

十小时是内容目标，不是工期、实测通关时间或完成承诺。一次外出没有统一强制时长，按玩家选择的目标和实际行程决定；3∶3∶4 不作为限制自由行动的计时配额。

## 02  世界背景与人物

森林狩猎、农耕与手工业混合的架空古代部族。

依据：Q009—018、Q031—040、Q101—108；Q183、Q208、Q209

### 2.1 社会与资源

部族同时使用石制工具和稳定的金属工艺，矿产相对有限。敌方为资源与土地发动战争。部族名称、文化细目、服饰、建筑样式和地理原型尚未定案；不将现实器物参考直接扩写成整套历史设定。

### 2.2 夜袭与逃亡

敌人在夜间准备充分地突袭，主角原在休息，防御薄弱导致失守。部分族人在开场故事中遇害；主角与弟弟带幸存者趁夜逃入丛林。敌方主力离开、丛林难以搜索及误判幸存者已逃远，解释营地初期得以发展。主角不默认有长期旧伤。

| 角色 | 稳定定位 |
| --- | --- |
| 主角 | 首领、最强战士；处事风格由玩家塑造，重要管理决定由玩家拍板。 |
| 弟弟 | 亲弟弟与心腹，缜密、温和耐心、有幽默感；随主角成长，不设好感或默契数值门槛。 |
| 普通族人 | 初始 20 人，不含兄弟；首版最多救回 10 人。少数有个性，其余重在劳动和生活氛围。 |
| 敌方战斗人员 | 普通敌人默认战斗到底；重武器、射手及其他兵种按配置作战。 |
| 敌方非战斗人员 | 受保护的场景人物，不作为全歼目标。 |

### 2.3 人物生命与故事边界

正常游玩中普通族人不可死亡；开场既定伤亡属于故事前提。弟弟不允许永久死亡后继续游玩，真正死亡与主角死亡一样要求回档。局部支线可以有不同结果，主要结局方向固定。

短刀参考唐横刀、长刀参考唐陌刀、钝器暂以狼牙棒为方向，均记录为用户指定的造型／战斗参考；本文未对历史形制作考证或擅自将“短刀”改名。

## 02  主线阶段与幻想能力

故乡的变化是首版终局，不以第二次战争延长首版。

依据：Q004—007、Q017—018、Q096—100；Q151、Q208、Q266、Q270

| 阶段 | 内容 | 完成后的变化 |
| --- | --- | --- |
| 夜袭与突围 | 过场后进入可操作段，体验潜行、战斗和弟弟协作。 | 推进到逃亡过场，抵达隐蔽营地。 |
| 立足与发展 | 安排生产，建造设施，获取食物、材料与阶段工具。 | 增加可行的生活与行动方式。 |
| 反复潜入 | 玩家自主取物、救人、击杀驻军并夺取分区。 | 清敌与控制进度变化；刷新边界见 R01。 |
| 夺回故乡 | 达到全歼及四个主要区域控制条件。 | 故乡直接开放为第二营地。 |
| 首版通关后 | 两地共享库存、经营及继续探索。 | 保留胜利时间线，不强制回到终战前。 |
| 完整游戏扩展 | 反击敌方腹地，带领战斗小队，使敌军失去对抗能力并投降。 | 首版不实现这一阶段的完整玩法。 |

### 2.4 叙事承接

救援与取物等支线长期有效。先夺回故乡也不取消未完成支线，但具体任务必须另写安全阶段的可完成入口；不自动重复发奖，也不默认全部任务被自动结算。故乡是同一处空间从敌占转为可生活区域，不是凭空出现一张新地图。

### 2.5 已纳入的特殊能力

主角可感应近处目标，产生类似透视的敌人轮廓描边，服务于潜行。当前只确定效果方向，未确定探测半径、持续时间、冷却、消耗、解锁节点和能否识别不同楼层。不得据此自动揭露地图上的全部敌人或把信息同步给弟弟。

### 2.6 仍为候选的占卜

占卜可预测自然信息，例如次日天气，仍属候选。天气目前只影响氛围，因此不能擅自附加种植、捕鱼或战斗增益来使占卜有数值用途。

## 03  核心循环与开场体验

准备、协作、执行、获取结果，再改变营地与下一次选择。

依据：v0.2 第 3 章；Q004—008、Q022、Q038；Q160、Q203、Q252、Q266

| 循环层级 | 明确流程 |
| --- | --- |
| 即时场景 | 观察地形与敌人 → 选择接近方式与分工 → 执行 → 应变、继续或撤离。 |
| 一次出行 | 决定目标 → 准备物资 → 与弟弟近距离协商 → 行动 → 带回成果或继续探索。 |
| 长期发展 | 营地设施与条件积累 → 提交材料提升营地等阶 → 阶段工具和角色成长 → 故乡夺回 → 双营地使用。 |

### 3.1 可操作开场

夜袭第一段过场之后，敌人进入兄弟所在核心据点，玩家立即接触移动、战斗、潜行及伙伴指令。首次协作就在夜袭段出现。教学可提供暗杀与正面应对机会，但不强制所有玩家完成一场不可绕过的正面战斗。

### 3.2 营地与探索互相供给

普通族人按面板分工生产，玩家或弟弟自愿加入可提高局部劳动产出。外出带回材料、特殊工具、图纸、装备和族人。玩家不用亲自满足每位普通族人的饥饿、床位与疗养需求。生产的新“一次性资源”方向必须先完成定义，见 R03。

### 3.3 行动结果

物品真实获得、建筑完成、族人获救和区域控制才形成结果。计划、对话承诺不直接等同于完成。副本式刷怪不自动等于新的主线成果；四日敌人刷新与永久清敌的衔接尚未闭合，不能继续无条件沿用旧版永久不复活承诺。

### 3.4 内容数量与节奏

首版目标约 8 个主要阶段目标、15 个一次性支线目标，救援规模与最多新增 10 名族人的限制一致；具体任务名单与拆分未编写。自由探索和生活活动补充体验，而不是为了凑十小时强制刷取。

开场战斗目标、教程文字、跳过规则及检查点位置尚未配置。首次显著成长约 60 分钟是阶段节奏目标，不应擅自等同于第一小时绝无经验、奖励或其他进展。

## 04  开放地图、通行与导航

已知地形、发现过程与任务提示分开呈现。

依据：Q019—024、Q027—030；Q157、Q177—178、Q267—268

### 4.1 空间与地形

首版核心空间为隐蔽营地、外围自然区域和被占领故乡。森林、草原、河流、河岸、山坡、山峰与洞穴均可采用，但具体区域面积、各地形数量、道路与兴趣点位置未定。敌方腹地不纳入首版。

| 参数／信息层 | 当前规则 |
| --- | --- |
| 基础通行 | 自由游泳、越沟及攀过低矮障碍；不等于可攀所有悬崖。 |
| 移动速度 | 常态 3.5 米／秒、冲刺 6 米／秒为已采纳的候选基线，整体偏敏捷。 |
| 营地至故乡 | 常规单程约 7 分钟以上；不得自动用直线距离替代曲折路线时长。 |
| 有效兴趣点密度 | 新路线平均每 90—150 实玩秒一次值得判断或互动的发现；普通木石不计入。 |
| 迷雾清除 | 沿已走路线，以约 100 米半径清雾。 |
| 常规地图 | 地形与传送点；故乡已有表面地形知识，不附完整文字说明。 |
| 任务叠加 | 选中任务后才临时显示准确位置／路线或搜索范围。 |
| 室内分层 | 首版暂不制作。 |

### 4.2 探索与信息边界

清雾不自动识别全部宝箱、敌人或隐藏任务。近处敌人轮廓能力与地图底图是不同信息入口。常规地图不默认维护完整实时敌情、时间戳和来源标签。

### 4.3 传送点的发现

靠近时发现，交互后才允许传送，明确分成发现与激活两个步骤。发现但未激活的点如何在地图上显示、有效发现半径和交互距离仍待配置；不再采用靠近即完成全部解锁。

速度与路程的条件折算：若七分钟全部以 3.5 米／秒无停顿前进，路径长度约 1,470 米；该值只用于尺度核对，并非地图直径或已批准的路径长度。

## 04  世界时间、暂停与跳时

世界日历与实玩计时分开；睡眠结算尚有关键空白。

依据：Q025—028、Q052；Q152—156

| 事项 | 现行规定 | 边界 |
| --- | --- | --- |
| 世界日历 | 现实运行 24 分钟＝游戏 1 日；1 实玩秒＝1 游戏分钟。 | 仅正常运行，不含暂停与跳时。 |
| 短动作 | 建造／扶起 5 实玩秒，用药 3 实玩秒。 | 不受日历流速缩放。 |
| 警戒／倒地 | 均为 2 实玩分钟。 | 替换旧版 5 分钟。 |
| 暂停 | 默认查看界面暂停；默认暂停期间各类倒计时冻结。 | 关闭一般暂停后，弟弟界面是否仍强制暂停未明确。 |
| 睡眠 | 在夜晚与白天之间切换，不计算具体时间流逝。 | 同时又要求结算营地产出，结算依据未定。 |
| 篝火休息 | 可以自由选择跳过时间长短。 | 可选范围、危险中限制及各系统结算未定。 |
| 天气 | 晴、雨、多云、雷暴雨仅影响氛围。 | 不改变探测、种植、火焰等规则。 |

### 4.4 睡眠与生产的保留要求

睡眠同样计算营地产出；生产资源被定义为“通过游戏内容获得的一次性资源”，用于避免快速刷资源。当前未说明这指有限投入品、生产许可、一次性产出点还是其他方式，因此不能擅自按任何一种模型结算。

### 4.5 跳时不能暗中补规则

睡眠只切昼夜但又结算生产，尚缺一次切换折算多少产出的依据。篝火跳时是否推进饥饿、死亡倒计时、作物、繁殖和资源刷新，均不能自动由“结算营地产出”推导为全部同速结算。

R02／R03：这是当前经济与时间规则的高优先阻塞项。保留原要求，不以新增睡眠冷却、强制口粮消耗、隐藏产出封顶等未确认机制代为解决。

## 04  资源刷新与快速旅行

允许在传送点进行战斗撤离；撤离同时伴随敌人血量刷新。

依据：Q052、Q087—095；Q156—159、Q196、Q268

| 对象／情境 | 已确定规则 | 尚待确定 |
| --- | --- | --- |
| 敌人 | 间隔 4 个游戏日刷新。 | 适用区域、首次日期、驻军与已夺回区域是否例外。 |
| 树木 | 间隔 14 个游戏日刷新。 | 统一日期还是采伐后计时，建筑占地如何处理。 |
| 其他自然资源 | 本轮未逐项替换的二日基线保留为待核对沿用项。 | 与一次性生产资源的范围关系；不能据此承诺无限供给。 |
| 农田／圈养动物 | 采用各自成熟、繁殖和成长周期。 | 跳时结算和个体刷新边界，不能直接重生重复个体。 |
| 传送出发 | 必须站在某个传送点；目标须已激活。 | 站点使用范围和中断表现。 |
| 传送成本 | 不消耗物资，不推进游戏时间。 | 无额外默认消耗或冷却。 |
| 战斗中传送 | 允许直接替代撤离，敌人血量同时刷新。 | 刷新哪些敌人、是否包含死亡对象与异常状态。 |
| 弟弟随行 | 交战中的弟弟无论距离都一起传送；其他状态不受影响。 | 倒地如何归类；非交战跟随者离开后的后续行为。 |

### 4.6 旅行与伙伴距离

战斗传送随行是明确的特殊例外，不能用日常 30 米交流边界阻止。反之，不能默认把远处留守或生产中的弟弟一起传送。免费传送也不等于个人背包远程访问共享仓库。

### 4.7 刷新的时间尺度

不跳时且连续正常运行，4 游戏日约为 96 实玩分钟，14 游戏日约为 336 实玩分钟（5.6 小时）。十小时首版因此可能跨越多次敌人刷新；这不是仅在通关很久以后才发生的边缘规则。

R01／R05：四日刷新与“永久清敌”尚未统一；传送刷新血量不能自行解释成所有驻军复活，也不能擅自仅限定于眼前一名敌人。

## 05  普通族人与营地劳动

二十名初始劳动力，生产不依赖首领亲自维持每一项日常需求。

依据：Q031—040、Q046、Q102、Q106；Q209—212、Q220

| 经营对象 | 当前设计 |
| --- | --- |
| 初始人口 | 普通族人 20 人，兄弟另计；少数重点人物，其余体现生活与劳动。 |
| 救援增加 | 最多增加 10 名普通族人；两营地不重复计算人口。 |
| 岗位分配 | 通过简洁面板按生产区域分配人手；持续生效，无需督工。 |
| 单区域上限 | 每个生产区域最多 5 名普通工人；各建筑升级后的容量变化未另定。 |
| 基础生活目标 | 投入 4 名普通工人可勉强维持基础生活；具体消费与产出表尚需配套。 |
| 主动劳动 | 一个主角或弟弟相当于 3 名普通工人的同类有效劳动。 |
| 外出安全 | 普通族人只在安全作业区工作；正常游玩不可死亡。 |
| 无需模拟的需求 | 不逐人计算床位、睡眠与个人饥饿，不设置缺粮死亡或罢工。 |

### 5.1 劳动倍率的适用范围

兄弟加速作用于实际参与的工作，不意味着其中一人坐在营地便能将全营地产量乘三。基础生产在兄弟外出后仍继续。三倍等效劳动是否占用五人岗位上限、与手动照料收益怎样叠加，仍待配置。

### 5.2 生活与互动

族人会工作、走动、休息、交谈。玩家可参与吃饭、听聊天、简短请求和休闲互动。已确定范围并不等于每类活动的台词、数量与交互已完成。固定台词均使用人声，需另编对白清单。

### 5.3 救援反馈

救回族人增加劳动力，或提供新制作／锻造配方与敌情；不为每位被救者增加独立个人故事。无床位接纳门槛、救援时限和必需疗养期；获救后必须有实际人员与奖励反馈。

## 05  营地等阶、建造与仓储

等阶靠条件和材料提交，建筑升级各自独立。

依据：Q041—050；Q201—203、Q215—218、Q220

| 事项 | 现行规则 |
| --- | --- |
| 营地等阶 | 上限 8 阶；两营地共享这一发展等阶。 |
| 升级方式 | 不设营地经验；满足规定条件并提交材料后，玩家点击升级。 |
| 具体建筑 | 各建筑分别升级，不因共享营地等阶而同步升满。 |
| 可建范围 | 第一营地基础半径约 50 米；营地等阶每次提升自动增加 10 米。 |
| 建造 | 营地内自由摆放，5 实玩秒读条完成；野外仅可建篝火。 |

| 仓储 | 双营地访问同一份库存，容量无限；不是复制两份物品。 |

### 5.4 建造成本的体验标尺

从零开始，以约 3 分钟主动采集取得第一座工作台所需普通材料；后续核心设施约需 15 分钟主动采集量。该目标不等于已经确认具体木石配方，也不包含自动确定的跑图、制作或剧情时间。

### 5.5 产能增长方式

第二营地不额外附加全局生产倍率，依靠新增生产位置和更高设施等级扩展产能。劳动力仍为同一池；增加地点本身不会无条件将同样人手的总产量翻倍。建筑等级对产出、岗位和配方的实际收益须在表中体现。

半径的条件折算：若以第 1 阶为 50 米且升至第 8 阶共提升七次，则半径为 120 米。起始阶及第二营地是否同样扩圈未明确，该结果仅是计算示例，不新增确定上限。

### 5.7 缺粮后果

缺粮只失去使用公共食物的便利，并可能引起族人抱怨；不会导致普通族人伤害、死亡、生产惩罚或冲突。玩家和弟弟的个人饱食度仍按各自规则计算。共享库存有食物，不等于已经自动分配进公共口粮池。

### 5.8 双营地开放

故乡夺回后立即可用；第一营地保留，库存共享，不要求运输队或人工搬运。普通族人的分布自动形成生活氛围，玩家不逐人迁移。故乡哪些设施现成可用、哪些需玩家新建，尚无建筑清单。

床铺自然恢复候选基线为休息状态每秒 2% 最大血量；治疗区只明确“更快”，没有确认具体倍率或使用材料，不能在配表时直接写成免费瞬间满血。

## 06  材料阶段、制作与耐久经济

三阶段工具链；工作台制作即时完成。

依据：Q010、Q051—060；Q186—187、Q221—225、Q229—230

### 6.1 资源阶段

石制工具 → 基础金属工具 → 高级金属工具。更高阶工具既解锁更高阶资源，也显著提高低阶采集效率。矿石 → 金属锭 → 装备的加工链需要燃料，可消耗木材。具体矿种、锭产率、燃料消耗与工具配方未配置。

| 制作对象 | 知识与使用规则 |
| --- | --- |
| 普通装备 | 作为已有知识直接允许制作；仍须具有实际材料与对应设施。 |
| 稀有／强力装备 | 只取得实物，不自动获得重复制作能力；需要收集图纸学习配方。 |
| 超前装备 | 提前获得可立即使用，不增加角色或营地等级装备门槛。 |
| 工作台制作 | 不消耗制作时间，即时完成；不继续使用旧候选的五秒批量制作。 |
| 有限材料 | 不设计划预留或库存锁定；实际材料不足就不能完成。 |
| 特殊工具 | 保留阶段门槛，但不能构成必须先持有本工具才能取得本工具的循环依赖。 |

### 6.2 耐久与维修

普通武器、工具损坏后暂时无法使用，可以修理；稀有、唯一装备通常同理。唯一装备耐久显著高于稀有装备。极少数强力装备允许“无法破坏”或极高耐久，按单件配置列为例外，不能擅自给全部高级装备无限耐久。

### 6.3 维修标尺

初级武器目标是正常击杀约 20 名同级普通敌人后需要维修，满修成本暂按制作材料的 20%。具体耐久总值、命中／格挡／暗杀耗损、局部修理和无法自制战利品的修理材料仍待定。防具各部位独立耐久，归零后的减伤处理也待定。

“所有在工作台的制作即时完成”已确认；是否包括独立冶炼炉、烹饪设施及弟弟全部加工动作的时间，需要明确设施口径。建筑放置仍为五秒，不随制作即时化而取消。

精确命中与接近位置决定猎物是否逃跑。统一头部要害不等于所有猎物都必定一箭死亡；弓伤害、各物种血量与头部倍率还需要对照。无需擅自扩展复杂伤口追踪、皮毛品质评级或疫病系统。

### 6.5 风险与弟弟

弟弟可在玩家参与的同行情境协助狩猎。独立任务仅限安全事务，不允许用独立狩猎指令绕过潜在致死任务限制。猎物过近敌区、出现危险动物或路线不安全时的中止条件需与伙伴权限统一。

### 6.6 名录配置空白

尚缺各物种活动区域、血量、固定伤害、移动速度、发现范围、掉落数量与刷新密度。狼的 3—4 块肉是已给出的说明性例子，不等于其余七类野生动物已具备名单与产出表。

### 6.8 与其他系统的联系

鱼是四类动物内容的一部分。天气只影响氛围，不能自动提高咬钩率。成功消耗鱼饵与否、鱼饵的制作成本、鱼竿耐久和鱼类料理收益尚未定；不能凭较短钓鱼时间就断言它优于狩猎。

仅用于风险估计：若连续每 8—12 秒成功一次、每次独立 2% 获宝，则每小时约 300—450 次成功，对应平均 6—9 次宝藏。实际还受鱼饵、找点、失败和界面停顿影响；2% 并不自动代表低频奖励。

个人食物供兄弟外出使用，公共口粮供营地进食便利。每块肉可制作一份料理的例子不等于所有肉类和鱼类都固定恢复 40；具体菜谱需明确输入、份数、效果与重量。食物不会腐败，但依然受到携带重量和使用需求影响。

视野限制同时使用四周暗角、可见距离缩短和镜头视角收窄。具体强度、最低视野以及是否提供舒适性设置未定，不能把三种效果都直接设到最大。10% 血量是饥饿掉血目标，不提供对其他伤害免疫。

### 7.2 恢复上限尚未统一

新答复否定按饱食分档限制回血，明确应可恢复到满血；另一答复又要求药品不能超过饱食限定的自然恢复上限。两项并存时，尚不能生成一致的恢复公式。前轮提问中的 75%／30% 候选分档不生效。

已可计算：100÷48≈2.083 饱食度／实玩分钟；单独处于两倍消耗状态时约 4.167／分钟，即满条约 24 分钟。该推算不决定复合状态叠加，也不包括睡眠跳时。

### 7.3 不擅自确认未回答的药品数值

速效恢复 30%、持续药 15 秒恢复 50% 来自提问候选，本轮没有明确接受它们，只明确治疗上限和重复规则。因此本版仍将治疗量、持续时长和药品成本留待配置。用药能否移动，也没有被“受伤中断”完整回答。

### 7.4 恢复与饥饿的冲突处理

零饱食主动掉血时，自然恢复是否停用、药品是否能短暂对抗掉血，以及“都可满血”是否只适用于非零饱食，均未定。本文不通过隐藏禁止回血减益、默认药品无效或重新添加饱食上限曲线来补空白。

单独考察已确认恢复速度且没有上限、持续伤害或中断：恢复半条血分别约需战斗 500 秒、非战斗 100 秒、休息 25 秒。属于算术折算，不是已通过测试的战斗平衡结论。

条件推算：若 12 秒指恢复阶段本身，则初始恢复量约 8.333 点／秒、举盾 5 点／秒、冲刺耗耐约 6.667 点／秒，满条可冲刺约 15 秒。12／20 秒是否包含 0.5 秒启动延迟、后期上限提高后恢复量如何增长尚未确认。

### 8.2 相对标尺不等于完整伤害表

普通敌人绝对血量、武器攻击间隔、伤害取整及多段命中未定。本文不擅自将普通敌人设为 100 血，也不把“五次攻击”换成某个未经确认的固定伤害后对所有部位通用。

条件例子：主角初始 100 血、五次相同命中倒地，可用每次护甲后 20 伤害作为校准点；若躯干减伤恰为 5%，对应护甲前约 21.05。它只是可行校准，不是唯一答案或最终伤害值。

### 8.4 防御与友军

### 8.5 投掷流派的成本空白

要让投掷成为主要流派，仍需制作成本、携带量、投掷间隔、有效距离和补给来源；60% 伤害仅确定单次相对效果，不意味着无成本无限使用。

| 已经取得控制 | 其他区域敌人再追入，不取消已取得控制权。 |
| 夺回必要条件 | 全部敌军已清除＋全部主要区域控制。 |
| 可选内容 | 救援、取物与破坏不是全部必做清单。 |

### 9.1 综合进度表达

清敌部分占 70%，区域控制占 30%，同时显示两项原始数量。若 K 为按最终规则计入的已清敌数、N 为总敌人数、C 为已控分区数，则 P＝70%×K／N＋30%×C／4。基础状态 N＝80；特定增援出现后直接增大 N，允许百分比回退。

### 9.2 收尾与卡死处理

清敌比例严格超过 95% 后，允许开启剩余敌人大致位置提示。落到不可达位置的敌人可回到原岗哨并保留当前血量。普通尸体不作为活敌目标，隐藏待触发增援怎样参与结束判定仍需任务明确。

无增援时，每名敌人对应约 0.875 个百分点，每个分区对应 7.5 个百分点；80 人的严格“超过 95%”意味着至少已清除 77 人。显示取整不能提前宣告 100% 完成。

## 09  刷新冲突、控制转换与后续方向

敌人刷新不能和故乡永续胜利同时使用未经定义的计数。

依据：Q094—100；Q156、Q158、Q197—200、Q270

### 9.3 当前需裁定的核心冲突

四日敌人刷新已成为最新要求；永久清敌、全歼驻军和控制四区仍被保留。尚未确定四日刷新是否作用于故乡、已清除敌人是否复活、进度是否回退，以及已夺回故乡是否停止刷新。本版明确登记 R01，不把“只刷新野外敌人”或“家园永不刷新”擅自补成规则。

### 9.4 传送后的结果

战斗传送允许撤离并刷新敌人血量，但刷新范围和是否影响死亡、警戒、异常状态、进度未定。不能把血量刷新与四日重生、下一次潜入击晕苏醒合成一个统一重置按钮。三种机制要分别验证。

### 9.5 故乡转为第二营地

满足最终胜利条件后，故乡立即开放为第二营地。第一营地仍可使用，两地共享无限仓储和营地等阶，建筑各自升级。前期破坏故乡设施不追加特殊重建惩罚；具体既有建筑的可用状态尚需清单。

### 9.6 未完成支线与战利品

支线长期有效，夺回后保留完成入口。重要物品与一次性奖励不能因新阶段或刷新而重复领取。四日重生敌人是否再次给经验、普通掉落与关键物品，尚未定义；这会影响六十级成长和资源总量。

### 9.7 首版之后

首版不包含敌方腹地反击与战斗小队。完整游戏仍以削弱对方军队并使其投降为方向，不要求杀害平民。通关后继续经营，不强制回到最终行动前；该体验需要 R01 明确保护或恢复后的区域规则。

本章不以降低全歼门槛回避冲突，也不否定已确认的四日刷新。必须先确定重生对象、进度计数和夺回后状态，才能把首版结束条件标记为完全闭合。

## 10  弟弟的职责、同行与安全边界

三十米内可交流，战斗与劳动各有明确权限。

依据：Q101—110、Q118—120；Q212、Q247—249、Q251—252

| 状态／功能 | 当前行为 |
| --- | --- |
| 人格 | 温和、耐心、缜密并有幽默感；严格处于世界观内。 |
| 同行判定 | 在主角身边约 30 米内可交流即视为同行，不要求额外视线条件。 |
| 近距离交流 | 半径约 30 米内仅需距离足够；不把隔墙默认判为不可沟通。 |
| 跟随 | 不主动采集，除非玩家明确要求。 |
| 协作战斗 | 可双人战斗、分路引敌、一人牵制另一人搜索或夺旗。 |
| 留守 | 按现有安排参与劳动，不擅自改变玩家岗位分配；等效三名普通工人。 |
| 独立任务 | 只做安全生产、采集、烹饪、养殖等事务，不独立暗杀或执行可能致死目标。 |
| 受阻 | 无法继续则安全返回营地等待玩家，不能隔空完整报告。 |
| 背包与交付 | 独立背包；采集成果默认回营放仓库，容量不足可分多趟完成。 |

### 10.1 可解释的拒绝

采用具体可预期边界：独自进入敌占区、路径明显不可通过、必死环境等可说明原因的任务可拒绝；不以随机评价“愚蠢”替代规则。同行战斗可以冒险，不能把独立安全约束误用于禁止所有协同战斗。

### 10.2 自动维持自身状态

候选阈值已接受：饱食度低于 25% 时使用自己的食物；血量低于 35% 时在适合用药的时机治疗。玩家能否修改阈值、稀有药品权限、缺药时行为和药品优先顺序尚未确定。

三十米同行边界与战斗传送“无论距离都带走交战弟弟”并存，后者是特殊明确例外。被迫分离时能否继续当前战斗、如何退出同行状态，仍需异常行为规则。

## 10  委托、覆盖与多趟执行

一个目标、最多三个步骤，不把执行循环误当成无限任务规划。

依据：Q111—117、Q123—124；Q249—252、Q258

### 10.3 目标与确认

复杂委托最多一个明确目标、三个步骤。目标、数量或关键条件不清楚时先确认；“帮我准备出门”不能直接套用未经确认的出行包。玩家可以提出当次禁用材料等限制，但没有全营地计划锁料或资源预留。

| 任务状态 | 应发生的行为／反馈 |
| --- | --- |
| 待确认 | 指出缺少的目标或约束，等待必要信息。 |
| 执行中 | 展示当前目标和至多三步安排；计划不等于成果。 |
| 多趟搬运 | 为同一个数量目标反复采集、回营入库并继续，不要求一次背包装完。 |
| 无法继续 | 返回营地等玩家；已经获得的物资不丢失。 |
| 建议尚未批准 | 只要原计划实际仍可执行，继续原计划；不能与真正受阻混淆。 |
| 新的命令 | 直接覆盖旧的对应命令，不要求额外确认覆盖。 |
| 完成 | 以真实库存、目标数量或世界结果为准。 |
| 取消／召回 | 停止尚可停止的部分；已完成行为不倒退，随身物品保留。 |

### 10.4 当前与长期安排

未声明持续时限的约束默认仅作用于当前任务；“以后一直”等约定持续至撤销。新的冲突命令直接覆盖旧安排，但具体覆盖到当前目标还是多条长期约定需要明确定义。撤销对应知识后不得再次执行已取消安排。

### 10.5 执行范围

多趟搬运是同一目标的重复执行，不自动增加新的任务目标或赋予任意规划能力。若资源耗尽、路线受阻或出现危险，返回等待，而不是无令更换资源点或把目标改成其他物品。

不设计命名整套行动并按名称调用的计划库，不设计好感或默契数值门槛。自然语言能力通过目标、数量、限制、覆盖和结果反馈体现，不靠未经授权替玩家改变游戏目标。

## 11  知识、世界事实与角色认知

世界真实状态、弟弟知道什么、玩家说过什么分开。

依据：v0.2 第 11 章；Q121—128；Q253—256

| 信息类别 | 记录与使用边界 |
| --- | --- |
| 初始知识 | 世界观、人物身份、兄弟关系、故乡地形与基础常识；不是占领后全知情报。 |
| 实际世界状态 | 真实库存、公共口粮、建筑、劳动力、装备、战果及任务状态；按实际事件更新。 |
| 角色已知信息 | 离营时不自动知晓营地后续变化；回营后更新。 |
| 独自行动结果 | 主角独自行动后，弟弟在回营后自动得知结果，不取得完整行动过程。 |
| 交流与约定 | 玩家原话的概括记忆、当前目标、偏好、长期命令。 |
| 共同经历 | 两人实际参与或获知的经历，不能从未来或其他存档分支取得。 |

### 11.1 玩家说法的权限

玩家表达可以改变弟弟的认知，不能直接改写客观世界。说“仓库有一百份粮食”不会生成实际物品；实际取用时仍按真实库存处理，不足则任务受阻。玩家说法优先不等于世界编辑或无限资源指令。

### 11.2 可编辑知识范围

玩家只能修改说过的内容及对应记录，不能修改世界实际发生的事。真实库存、建筑等级、完成的任务及客观人物身份不得因口头撤销而改变。删除约定可停止该约定；删除一句话不撤销已发生的建造、伤害或救援。

### 11.3 信息更新时间

弟弟回营后更新营地变化和主角独自行动结果，保留“只知结果、不虚构过程”。玩家仍可通过三十米内的交流传达信息。远离营地的角色不因后台世界记录更新而自动获得即时知识。

不以“世界已记录”替代“角色已经获知”。玩家修正过的口头信息、实际观察结果与旧记忆发生冲突时，仍必须保证实际行动和库存结算真实。

## 11  串行交流与全局快捷建议

三条建议只在主动刷新时更换；动态交流仅使用文字。

依据：Q130、Q147；Q256—258、Q269；沿用两阶段与本地模型设想

| 交互环节 | 职责 | 可见结果 |
| --- | --- | --- |
| 全局快捷建议层 | 使用最新营地及已允许的信息，面向玩家提供可做事项；不等于弟弟自己全知。 | 显示 3 条建议，只在玩家主动刷新时更换。 |
| 第一串行阶段 | 根据玩家输入或选择识别意图，激活相关知识。 | 不每次把全部历史和世界状态装入同一轮。 |
| 第二串行阶段 | 接收玩家原话及被激活知识，在人物与权限边界内回复。 | 回复、必要澄清和目标步骤。 |
| 实际执行与沉淀 | 只有真实动作、库存、目标或场景改变后更新执行结果。 | 区分计划、进行中、完成与受阻。 |

### 11.4 已保留的设计结构

采用向量知识库与检索增强方向。初始知识、概括后的玩家表达及世界变化分别存储并按需激活。两层语言处理串行而非并行；全局建议的职责另于弟弟回复。约 4B 本地模型是既有设想约束，不是速度或可靠性已验证的结论，本文不展开技术方案。

### 11.5 建议信息上限

建议允许使用最新营地数据，但不揭示未探索宝箱、隐藏敌人和未知任务答案。玩家选中含新信息的建议后，视为把这一条告知弟弟；未选中的内容不进入其认知。不能为了建议有用而泄露尚无权获知的地图内容。

### 11.6 等待与文字量

可接受较长等待，必须显示“正在思考”以避免误认为卡住。普通委托回复约 30—60 字，复杂确认约 80—150 字。没有已确认的硬性响应秒数，不承诺实时返回；取消、关闭与迟到回复如何处理仍待边界。

所有动态回复，包括快捷建议触发的回复，都只显示文字。三条建议在世界变化后可能失效，点击旧建议时如何提示失效、是否重新确认，仍需明确，不能把陈旧建议当作已完成事实。

## 11  记忆管理、时效与时间线

回档恢复整套知识状态，不保留被撤销时间线的经历。

依据：Q117、Q123—129、Q150；Q250、Q253—258

### 11.7 查看与撤销

保留可查看、修改、撤销的知识清单，编辑对象限于玩家说过的内容。口头要求忘记相应交流，按撤销相关记忆处理，不再影响弟弟；仍不能删除世界实际发生的事件。固定身份属于世界事实，不可通过改一句话使角色脱离世界观。

### 11.8 约定时效

当次限制在当前目标结束后不自动升级成永久偏好；明确长期安排持续生效，直到撤销或被新的对应命令覆盖。删除长期安排必须停止它的后续作用，不允许旧条目重新激活后再次执行。

| 情境 | 一致性要求 |
| --- | --- |
| 库存变化 | 当前库存与“曾经带回多少”的历史记录分开。 |
| 建造完成 | 五秒读条真正完成后才写为建筑已建成；未完成不能先记为结果。 |
| 多趟采集 | 记录真实累计交付，不把一趟计划数量当成总量完成。 |
| 玩家撤销话语 | 停止对应认知或约定，不撤销已消耗的材料。 |
| 载入较早节点 | 恢复该节点的世界与知识；尚未发生的经历不得留下。 |
| 其他新游戏进度 | 不得检索其他角色进度或分支的记忆、任务与建议。 |

### 11.9 主动交流

沿用连续三个游戏日未与弟弟交流后，在玩家回营时主动闲聊或询问安排。正常运行相当于 72 实玩分钟。什么交互重置计时、主动闲聊属于固定还是动态内容、与睡眠跳时怎样衔接尚未细化。

### 11.10 不作未经验证的能力承诺

自由输入不是通关必经操作，快捷入口也可完成玩法。记忆和交流的价值要通过行为结果检验；记录了 270 项答复不代表所有语言表达、歧义和异常情境已覆盖。

## 12  任务目录与内容定义

八个主要目标与十五个一次性支线，是数量基线而非已写完脚本。

依据：Q022、Q039、Q096—100、Q146；Q209、Q238、Q266—270

| 内容类别 | 数量／范围 | 必须进一步提供 |
| --- | --- | --- |
| 主要阶段目标 | 约 8 个，覆盖首版夜袭至双营地。 | 触发、地点、步骤、检查点、结束条件与对白。 |
| 一次性支线 | 约 15 个；不因优先通关失效。 | 任务清单、完成方式、奖励及通关后入口。 |
| 救援 | 最多新增 10 名族人。 | 救援任务数与每项人数，不等于默认十个单人任务。 |
| 兴趣点 | 沿新路线平均 90—150 秒一次有效发现。 | 实际地图布点、奖励分层与距离检查。 |
| 藏宝图 | 钓鱼等已配置奖励来源中的候选内容。 | 图与箱一一对应、生成前置与唯一性。 |
| 生活互动 | 吃饭、聊天、请求、休闲等。 | 互动数量、固定台词及具体可见结果。 |

### 12.1 每个任务的最低定义

任务卡应包括：触发条件、地点与导航、目标对象、可用完成方式、弟弟职责、物资与经验奖励、成功与失败条件、回档恢复项，以及主线阶段变化后的承接。这里只规定字段，不虚构尚未给出的任务名称与故事内容。

### 12.2 奖励连接

探索可奖励角色经验、配方、特殊工具、稀有装备和玩法解锁。普通配方已知，强力配方主要通过图纸取得；工匠和救援奖励需要与这条最新规则对应，不能再默认拆解稀有实物直接学会。

### 12.3 关键工具与通关保证

每个必需工具必须存在不循环依赖的获取链。单次资源、图纸或敌军掉落不能在没有替代入口时被错误销毁而使通关卡死。具体补救条件属于待写任务规则，而不是现在就新增免费补发机制。

## 12  组合行动与验收用例

以下是规则组合示例，不是已确认的新任务脚本。

依据：第 4—13 章现行规则；Q191—200、Q249—256、Q259—260

### 12.4 准备与多趟采集示例

玩家在三十米内让弟弟取得指定数量的普通材料并放进仓库。目标清晰则执行；容量不足可分多次往返。资源实际不足或路线不安全时，弟弟返回营地等待。这个示例不假定资源点会自动无限再生，也不允许远程用新对话替他重新规划。

### 12.5 潜入与分工示例

兄弟在故乡分工，一人控制敌人注意，另一人搜索物资。可选择一秒击晕临时绕过，或三秒暗杀形成致命处理。发现尸体的守卫需要传播，玩家有三秒阻止窗口；成功传播后当前分区进入两分钟警戒。

### 12.6 战斗、夺旗与撤离示例

清除当前分区后进行五秒夺旗，其他区域敌人进入会中断读条。已完成的旗帜控制不因后续追入而丢失。到达传送点可战斗撤离，交战中的弟弟一起传送；敌人血量刷新，但具体作用范围必须待 R05 定义，示例不将它解释为死敌复活。

### 12.7 互救与恢复示例

一人倒地后有两分钟救援窗口，另一人可五秒扶起，不强制消耗救助药品，恢复 10% 血量并保留自然回血资格。双方同时倒地立即失败；独行倒地允许从一开始放弃等待并回档。

### 12.8 回营与记忆示例

真实带回物资进入同一共享库存。弟弟回营后更新营地变化，并得知玩家独自完成行动的结果，不虚构过程。读回出发前存档后，物资、任务、敌人、旗帜、时间和记忆一起恢复，不保留后来结果。

组合用例的价值是暴露跨系统空白。只要敌人刷新、跳时结算或治疗上限未闭合，就不能把整场示例标记为“全部规则已验收通过”。

## 13  倒地、互救与真正死亡

两分钟窗口，五秒扶起；双方同时倒地立即回档。

依据：Q131—138；Q152、Q170、Q259—261

| 状态 | 转换和规则 |
| --- | --- |
| 正常／低血量 | 未倒地即可行动，弟弟能自动用药；无长期伤残或疗养资格限制。 |
| 倒地待救 | 血量耗尽进入倒地，窗口为 2 实玩分钟。 |
| 放弃等待 | 倒地开始即提供主动放弃选项；没有可救援者时也无需被迫等完。 |
| 扶起 | 5 秒读条，不需要必需救助药品；主动移动或受伤中断，从头重试。 |
| 扶起结果 | 恢复到最大血量 10%，可正常跟随和自然恢复。 |
| 双方倒地 | 直接判定失败，需要回档。 |
| 真正死亡 | 倒地超时、倒地后继续受伤、不可救援环境及饥饿期限结束等。 |
| 失败后 | 主角或弟弟任何一人真正死亡，都不能继续当前进程，载入已有节点。 |

### 13.1 敌方与环境伤害

倒地后敌人改攻其他目标，不主动补刀；倒地者不等于对飞行中的投射物、范围伤害和环境伤害无敌。具体残留伤害怎样触发死亡需逐类配置。溺水窗口为十秒；停止游泳悬浮保持耐力不代表零耐力之后也能无限漂浮。

### 13.2 弟弟救助策略

优先创造能完成五秒读条的机会；倒地窗口剩余不足三十秒时提高救助优先级。此处改变的是目标优先，不是忽略障碍或伤害的保证救活。安全任务遇险时优先撤退返回营地，不向其发出独立致死行动。

### 13.3 回档是唯一失败恢复方式

没有自动复活后捡包、扣钱复活或弟弟永久死亡后的替代主线。读回哪个节点，就恢复那个节点的角色、装备和世界。关卡开头必须有可用初始节点；不能让首版夜袭开始后没有任何恢复入口。

### 18.2 怎样得到约六成半

按表中权重对分项判断加权，结果约 65%。权重由本次评估设定，分项属于基于文档的专业判断；60%—70%是判断范围，不是统计置信区间。没有按回答270题、页数或已列系统数量直接折算。

### 18.3 为什么不是八九成

主要系统与关键数值已明显前进，但还缺逐件装备和配方、六十级曲线、四系技能节点、十五类动物数据、四区地图和二十三项目标脚本。同时存在影响整个循环的五个P0问题。它们比零散小数值更接近设计剩余工作的主体。
