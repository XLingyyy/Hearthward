## D1｜默认操作与同键冲突

采用[完整操作表](../planning/TASK-051/INPUT.md)。保持WASD、鼠标、Shift、Space、E、Tab、T、B、M/K/J、F6、Esc等现有入口；保留045的左键轻击、Shift＋左键重击、右键格挡／瞄准、Alt闪避、中键锁定、V感应、F/R处决、G投掷。现有4键投掷可保留为副键，Q只旋转建造预览。

同一物理输入只由当前最高优先上下文消费一次：加载／失败／确认 → 重绑定捕获／中文输入框 → 当前菜单 → 钓鱼／建筑预览／已开始动作 → 世界交互／战斗。输入框有焦点时WASD/T/R/F等均输入文字，Enter仅提交已完成的中文输入；不能同时发委托并攻击。全局Esc/F6先由当前页面处理，不能在未确认操作下另开页面绕过确认。

R沿045：有效击晕 → 可访问仓储 → 弩装填；无有效对象不生效。E沿现有生存优先：扶起 → 放下／搬运尸体 → 回收箭 → 工作台 → 任务／站点 → 普通采集；新增低障攀越仅在显式攀越提示选中且前述对象均不适用时接受。相同层的多个对象按距离和稳定ID排序，HUD显示本次唯一动作。未能支付费用的高优先动作显示拒绝原因，不落到另一个收费动作。

Shift在同帧左键组合中解释为重击，攻击期间不扣冲刺费；持弓时Shift不把射箭改为近战。重新映射后判断修饰动作，不能继续读取写死的LeftShift。按住键打开页面、失去窗口焦点或读档后清理瞬态按住状态，重新按下才触发消费动作。

## D2｜重绑定、控制器、焦点与设置

首版候选承诺Windows键盘＋鼠标；控制器本轮排除正式交付，不绘制无效手柄设置或显示完整支持标志。若Owner选择支持手柄，需要另补完整战斗、建造、菜单与文字输入覆盖，不能只接左摇杆宣称完成。

所有玩家动作支持按语义分别重绑定，主／副键各一个；同键默认共享的R动作可分别绑定。允许单键及一个修饰键组合，显示冲突的动作和上下文；同时可用且语义不同的动作阻止应用，互斥页面允许复用。同键组合与单键冲突按D1消费规则处理。Esc返回、Enter文字提交和系统快捷键不重绑定；移动、攻击、交互和打开设置必须保留至少一个有效入口。F10布局编辑仅Development，不列为玩家动作。

映射草稿取消不生效；应用一次提交全部有效设置，重启保留。显示切换提供15秒保留确认，超时恢复原显示模式与分辨率；不会回滚同期已确认的非显示设置。没有现成设置文件的旧用户采用默认操作，旧世界存档无需因设备设置升级schema。

## D3｜基础通行与环境参数

保留常态3.5m/s、冲刺6m/s的已接受初配及044／047真实负重、耐力和状态修正。本稿不改变跳跃5耐力、战斗动作取消窗口或普通路径长度。

| 项目 | 新候选参数与接受条件 |
|---|---|
| 常规台阶／坡面 | 台阶≤0.45m，站立可行走坡度≤45°；胶囊能完整落地，不能只射线命中一个点 |
| 低障攀越 | 高差(0.45,1.20]m，前方≤0.8m，上方和全路径胶囊无阻挡；落点深度≥0.6m且站立面合格；E显式开始 |
| 攀越动作 | 1A秒，开始一次扣8耐力，无足够耐力拒绝；不提供无敌，受伤／主动取消／落点失效中止，不退已付耐力；保持实际碰撞位置，不能取消后穿墙或瞬移到起点 |
| 水中活动 | 普通游速3m/s，无水中冲刺／潜水攻击；有地面支撑时浅水步行，无支撑才游泳。WASD划水；停止输入且实际水平速度<0.05m/s时悬浮 |
| 游泳耐力 | 主动划水每A秒耗Smax/25，再乘047通用耗耐修正一次；不恢复耐力；正耐力悬浮既不消耗也不恢复。初始无修正100耐力可划25秒／约75m，仅为纸面预算 |
| 零耐力下沉 | 耗尽后关闭悬浮，上限下沉0.5m/s；10A秒期限沿044。短暂出水不续命；到可呼吸且可站立岸线才解除，上岸另等0.5秒恢复；允许零耐力在真实支撑上步行上岸 |
| 普通地面坠落 | 用落地前向下速度v与实际重力g计算等效高度h=v²/(2g)，统一以m/s、m/s²计算。h≤3m不伤；3<h<12m，伤害=Hmax×(h−3)/9；h≥12m为Hmax，不受护甲／格挡减免 |
| 致零落地 | 可站立且可救落点转Downed，不能把12m等同无条件Dead；10秒溺水／死亡体积／无落点深渊沿044直接Dead。落水不同时套地面伤害和水下死亡两次 |

同次落地伤害只结算一次，落地后静止不再收费。数值驱动现有FallImpact速度接口，但百分比最大生命换算及落地分类要在唯一生存入口完成，不能硬塞一个固定100血曲线。暂停冻结攀越、游泳消耗、下沉和溺水；读档清理旧动作回调，不接着执行另一时间线的落点请求。危险中不新建存档；原有合法快照在水边／动作后恢复仍须重新检查碰撞和支撑。

所有主线必经通路继续能步行，净宽候选≥1.5m、净高≥2.1m；岸边须有步行出水面。伙伴只使用经现场检查的同类导航连接；已批准仅同行活动仍受050权限限制。没有合法连接就报告受阻并走步行回路，禁止穿墙或远距瞬移。攀越／游泳先验收选定路线，不承诺任意悬崖和全地图水域。

地图继承049稳定地点、发现与激活分离及100m清雾。不用颜色独自区分：未发现不显示未知答案，已发现用空心标志，已激活用实心站点，已控区附旗帜与文字；跟踪只临时叠加任务目标。新路线有效发现间隔90—150秒为既定目标，统计按实际正常步行且排除战斗／菜单停留，不能由直线坐标推定。

## D4｜字幕、固定对白与视觉舒适性

固定台词全配人声、动态回复仅文字，沿Q149/Q269和050；不新增TTS。固定对白使用稳定cue ID及说话人，字幕和声音同一事件触发；取消／过场跳过停止本段声音，真实已提交任务事实不撤销。读档不补播未来对白，重入触发器不重复播放已完成的同次事件。

[固定对白清单](../planning/TASK-051/fixed-dialogue.csv)盘点049的46个逻辑cue（23任务×2），文本相同可共用录音，另列8个本单候选的伙伴状态句。记录源、触发、录音复用ID和制作状态；这是文本／制作清单，全部录音UNPRODUCED。未写说话人的049通用句候选由弟弟说，须在30m内、已有观察或允许的任务回执成立时触发；否则仅显示任务文字，不能让他获知远方事实。新固定台词必须登记后纳入完整配音覆盖。

字幕默认开启，支持说话人文字标签及可调背景；动态对话保留滚动记录，不按语音长度截断。静音后仍可读取任务、发现条、警戒、倒地、溺水和行动受阻；保留GDD“不新增环境脚步方向性视觉提示”的范围。

严重饥饿候选视觉：暗角边缘厚度为短边15%、最高遮罩不透明度0.35；环境远景可见距离缩短到80m但保留HUD／交互提示；FOV比用户设置减少10°且不低于70°。三项用统一0—100%舒适性强度，默认100%；设为0只移除视觉限制，044移速−20%、输出−25%、劳动−30%和死亡期限保持。镜头震动不与饥饿重复叠乘；固定镜头、字幕和模态页不施加抖动。

这些表现不改变敌人权威亮度、感知范围、任务答案或地图清雾。天气继续只影响氛围；不能以玩家图形设置或FOV作为敌人感知输入。昼夜、极端亮暗背景和战斗中大字号字幕分别验收遮挡、文字和交互可读性。

## D5｜目标设备、画质与游戏／模型联合性能

候选目标为已有目标机档位：Windows 11 x64、i7-13650HX、RTX 4060 Laptop 8GB、16GB内存、SSD，接电且记录实际性能／散热模式、显卡功率和驱动。已读取本机物理内存约16GB；驱动577.00只来自fix2历史环境，复测必须写实际值。此为目标验收设备，最低配置与其他显卡支持尚未认证。

采用当前项目定制“极高”（sg档位3）、1920×1080、100%渲染比例、DX12 SM6／Nanite／VSM／原生TAA，关闭动态分辨率、帧生成、VSync并不限帧。画质字段和截图进入报告；不能通过改变分辨率／关闭敌人／暂停世界取得通过。旧Demo中等30FPS保持为历史发行策略，不替代本目标。

每个后端明确GPU layers（锁文件默认16；CLI覆盖另记）、线程、模型／运行库版本、token预算、上下文档位及并发1。不升级模型和依赖。依[测量协议](../qa/TASK-051/PROTOCOL.md)覆盖营地昼夜、序章、三敌战斗、归路流送和建造／经营；至少第二台无UE／Python的独立机器测安装与实际能力，CPU和Vulkan结果分开。一台或一个后端FAIL不能被其他PASS覆盖。

fix2已有营地76.88平均／66.34低帧、序章94.11／69.85，均为原源码固定视角且未运行模型。只能作为对照，本稿没有新的性能运行结果。
