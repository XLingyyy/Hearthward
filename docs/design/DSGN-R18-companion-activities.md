## D1 已批准：新活动的独立／同行权限

保持30米内按距离交流；受理、确认和撤销均走该边界，遮挡不新增交流限制。一个明确目标、最多三步，多趟只是同一数量目标循环。模型不得提供路径、库存真值、伤害或未知目标坐标。

1. **可独立**：已知安全点采集；同一营地内明确起终点搬运；已解锁设施的限定批次生产；已播种地块的浇水／照料／成熟收获；已有栏舍的喂食及普通产物收集。必须有已知地点、可达路径、真实材料、工具和授权；只执行已注册条目。营地危险时暂停工作并保全物资。
2. **仅同行**：野外狩猎、钓鱼、捕捉与牵引回营、敌占区潜入／协战、已接触救援者的护送。玩家指定具体目标或活动；弟弟不主动另开猎物、战场或救援目标，不代玩家完成剧情交谈、占旗和奖励选择。
3. **首版不支持独立委托**：进入敌占区杀敌、搜寻未知人物／宝藏、自动播种扩田／配种／宰杀、营地升阶／建筑拆迁、无限补货、“维持库存永远不少于X”和两营地运输。普通营地日常活动保持029现有低权限，不自动升级为生产委托。
4. 生产采用明确“配方＋批数＋设施＋材料来源”；开始前显示预计成本，实际消耗按领域服务结算。不能既计弟弟实际在岗工效，又额外生成一份委托产物。
5. 原来配方型craft／自有repair继续沿唯一执行器；正式实例维修应指定EquipmentId，原型ItemId唯一件语义只适用于旧证据，不能默默套用到047独立耐久实例。

独立活动必须逐项完成领域接口和真实运行验证后才暴露到能力目录；设计允许不等于当前能执行。详见矩阵。

## D2 已批准：同行越界、失败与物资保全

- 跟随30米是同行活动边界，独立安全任务受理后离开30米仍可执行。同行时超过30米，停止开启新的进攻／狩猎／钓鱼／护送操作，优先脱离威胁并追随玩家；已发生伤害和已提交事务保留。为脱离近身威胁的防御仍由UE控制，不继续追击。
- 回到30米内且目标、授权和安全条件仍有效，可继续原同行目标；目标已失效则报告并结束。不能自动换目标。跟随本身可以在30米外寻路接近，不因距离把角色锁死。
- 无法继续时，沿现有恢复器有限重试；有安全归路则返当前任务营地等待。若返营同样不可达，停在当前可站立安全位置，保留货物并记录原因；无安全落点时继续由生存／战斗处理，禁止瞬移、飞行或凭空回血。重试次数沿029原型配置，本单不把其数值批准为最终通行参数。
- 取消或替换：停止可中断动作，提交边界前释放预留，已经生产／采得／搬得的物品留在真实容器。不得因为换任务把任务货物清空、复制或计为新采集量。新任务可明确接管旧货物，数量口径必须区分新采得、携带和已入库。
- 多趟完成按本任务真实目的地转移回执累计；从仓库取出再放回不能刷交付。容量不足分趟，材料耗尽或目的地满则受阻，不能强制删物或换物品。
- 到营报到只由真实位置和Campaign注册表认定；带救援者跨站点不新增传送能力。043特许战斗旅行例外保持原样。
- 状态面板可显示客观受阻／计数，必须与弟弟台词区分。距离外暂存报告，30米内再交流；不能用面板让弟弟获知远方隐藏敌人。

## D3 已批准：当次命令、长期约定和撤销

沿用025：执行中的目标固定接受时约束版本；修改普通长期规则影响后续任务，需另行停止当前任务。界面明确显示“用于后续任务；当前任务仍按原约束执行”。

| 玩家动作 | 候选处理 |
|---|---|
| 提出新任务但尚未确认 | 原任务继续；未确认候选没有执行权 |
| 确认合法新任务 | 一次确认同时替换当前任务，不再弹覆盖确认；保留无关长期规则 |
| 新任务与长期强制规则冲突 | 不静默绕过；提示对应规则，由玩家明确修改／撤销，或取消新候选 |
| “以后不许用草药”改为“以后可以用草药” | 规范化为同一约束槽位的替换卡，确认一次只更新该条；“可以用”只是取消禁用，不授权远程取仓库 |
| “这次可以用草药” | 候选卡明确标出仅本次例外，确认后仅覆盖对应槽位；其他禁止与预算不变 |
| “取消当前任务” | 停止当前执行；长期约定仍在，货物保留 |
| “忘掉刚才那条约定” | 引用唯一记录后撤销；指代不清先列候选，不能删除全部记录 |
| “取消所有任务和约定” | 一张明确列出对象的卡，确认后取消任务并撤销所列玩家规则；不删除事实与回执 |

普通文字偏好只影响表达／检索；只有已支持的结构化约束可强制限制实际动作。不能把“省着点用”描述成已执行的数值预算。长期规则不自动生成重复任务，也不新增聊天次数或好感门槛。

## D4 已批准：自动维持与跨活动衔接

以下已由044批准，无需再次裁定：饱食低于25自动食物、生命低于35%适时用药；本人背包；普通速效优先；稀有／唯一药指定物品授权、随档保存、提交前复核撤销；危险先脱离，真实可达且赶得上时救兄长，2米无遮挡站定5秒；不足30秒提高优先级但不突破必死环境与通行能力。

新增已批准规则：

- 所有新活动均接受现有生存系统中断。救援中断生产时保留完成品与已结算费用，未完成部分按该领域既有规则处理；救援后原任务显示暂停，玩家明确继续才恢复消耗性工作。
- 将“允许自动使用稀有药”和“允许制造／搬运／消耗稀有材料”分开。药品授权不外推为配方耗材授权；仅搬运不等于可消耗。唯一任务物品不进入通用耗材目录。
- 新增耗材授权在扣料前复核，撤销立即阻断尚未提交的相应消耗；这与普通文字约束的接受版本冻结不同。完整／半份药中断费用继续沿044，不由050另设损耗。
- 未给物资或路径受阻时报告真实原因，保留手动指令和倒地放弃入口。模型不可宣称已服药、已扶起或已到营。

## D5 已批准：三日主动交流、过期建议与迟到回复

1. 采用W游戏分钟：最后有效交流后达到4320W分钟，仅形成一个待交流机会；跳过多日不累积多次。新游戏以兄弟首次会合时刻初始化；旧档无记录则以加载的W初始化，避免伪造历史交流。
2. 有效交流指30米内一条玩家消息被系统接收并得到可见回复（含澄清、拒绝），或玩家确认一条结构化命令／规则卡；在该次完成时重置。仅打开窗口、刷新建议、系统战果通知、未选建议、失败／取消的推理不重置。闲聊提示本身不重置，玩家回应后才重置。
3. 达到三日后，双方同处安全营地且可交流、没有战斗／倒地／读条／对话占用时，提供一次非模态短句。玩家忽略后本次回营不重复，下次离营再回营仍可提示；无强制答话、无关系惩罚。真正暂停不触发，睡眠可使W到期，醒来安全时再提示。
4. 任务失败、救援相关消息优先于闲聊；沿用已有队列、去重和冷却机制，不新增每隔若干分钟必须聊天的规则。保留重要事件的状态入口，队列淘汰不能抹掉真实任务结果。
5. 三条快捷建议仍仅主动刷新；点击前按世界／记忆修订、任务身份和时间线复核，过期提示“这条建议已过时，请刷新”，不偷偷改成另一个目标。可将旧项标为不可用，但不后台替换三条内容。
6. 关闭对话或取消生成使待回复和未确认候选失效，已接受任务继续。迟到回复不重新打开窗口、不生成执行卡；超出30米的回复不作为已传达交流。重新靠近后由玩家重试，不远程补执行。等待显示思考状态并提供取消／手动入口，本单不设未经实测的响应秒数承诺。

## D6 已批准：记忆修正、角色表达与回档

- 保留玩家原话、本人观察与行动回执的来源。现场事实推翻旧报告时更新Belief并给一次简短纠正，保留“先前听说／刚刚确认”的区别；不虚构玩家撒谎动机。
