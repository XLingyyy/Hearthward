# DSGN-002 · 020配套玩法配置

用户要求九页UI连同缺失玩法实现。GDD v0.3仍为基线；此文记录020新增可调内容，不将未回答的R项改成历史定案。

采用GDD明确数值：生命/饱食/耐力初始100；正常饱食48分钟耗尽、高活动双倍；正常350/冲刺600cm/s；回耐12秒、延迟0.5秒、冲刺消耗基础回复的0.8倍并受负重影响；角色60级、营地8阶、末期300生命/200耐力，新增值各半；四系技能，投入总成本最多60%，免费洗点；清雾100米；靠近发现、交互激活、在站点才可传送且不推进时间；个人容量100，共享仓库无限。

本单内容配置：节点名称、前置、效果、等级经验曲线、任务步骤/奖励、地点及发现/交互半径存入独立JSON。技能效果必须被真实状态/操作消费；任务奖励依据已发生行为发放且同进度只领一次。装备保留在个人库存计重，槽位只保存物品引用，仓储/丢弃后同步卸装。

健康冲突的020暂行规则：饱食大于0时可自然回满；零饱食时暂停自然回复并按五分钟降至10%基线；严重饥饿恢复至10饱食解除。睡眠生产、四日驻军刷新等未在本单UI配套闭环中定义的机制不顺带补定。上述暂行规则显式配置，R04保留OPEN。

本次地图内容与任务服务现有灰盒可玩空间，插画用于地图/菜单。插画中的大面积山河城寨并不表示已完成对应三维关卡。新任务先覆盖营地立足、采集入库、装备、进食、探索、激活传送与技能成长；完整八主线十五支线另需场景和剧情内容支持。

技术依据：Epic Data Driven Gameplay Elements、Saving and Loading Your Game、UMG Styling/DPI Scaling。布局以1672×941设计坐标配置，保持比例缩放；文字/图标/交互/数值均独立于背景。字体Noto Serif CJK SC，SIL OFL许可随文件交付。

020已补入药品、火罐投掷与材料修理；修理仅限安全营地。伙伴直线碰撞移动支持等待/跟随/进攻，障碍遮挡会阻止命中并报告原因，尚无完整绕障寻路。日志的见闻、人物、势力与物品收集使用实际解锁条件，具体内容在codex配置表。技能前置关系同时驱动学习约束与绘制连线。
