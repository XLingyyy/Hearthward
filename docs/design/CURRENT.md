## 已确认项目边界

单人、第三人称、UE5开放世界生存冒险。约十小时首版，夜袭→发展→夺回故乡→使用第二营地；
不包含反击敌方腹地、部族战斗小队与最终投降。目标体验约3:3:4，但不是强制计时配额。

20名普通族人，最多救回10人；营地8阶、人物60级；80名基础驻军、4个主要控制区。
两营地共享同一无限仓储与营地等阶，建筑独立，不重复计算劳动力与全局加成。
十五类动物范围为8野生、3家畜、4鱼，具体清单仍待配。

弟弟为深度交流伙伴：30米交流、安全独立任务、一目标最多三步、多趟实际入库、受阻返营；
真实库存与认知分开，不能用玩家陈述改世界。采用轻量意图处理/RAG/可知状态过滤 → 一次4B本机推理 → 结构化候选与NPC台词 → UE校验执行。
候选Qwen3.5 4B由llama.cpp加载GGUF，在玩家电脑运行；实际版本及测试见TASK-013。

真正死亡要求回档；两分钟倒地窗口、五秒扶起至10%血且可自然恢复；双方倒地失败。
全进度共享50点档池，默认10分钟自动保存、范围1—60；固定台词有人声，动态回复仅文字。
