# CT-TASK-051 动物动作与行为

物种动作配置是`Resources/Data/animal_motion.json`，来源和骨架由批量导入报告绑定。每种独立Skeleton；禁止跨物种、R2/R3或新旧SK混用。动作片段按导入时保存的真实对象路径加载，网格使用厘米制和导出正向。

`UHearthwardAnimalMotionComponent`统一拥有物种视觉状态和自然活动；现有自然Actor继续拥有048实体、伤害、捕捉、牵引、掉落和存档身份。普通运动片段依据实际速度调整播放速率，自然行为及死亡片段按原速。原生AnimInstance负责相邻姿态的短混合；致命伤害优先级最高，倒地后不恢复运动。

现有CombatTarget在已绑定动物动作时将倒地交给此组件，避免旧90°整Actor旋转与倒地动作叠加。没有动画资源的对象继续原行为。

演示Actor复用同一动作组件与CombatTarget，单独GameMode生成14只及真实弟弟，指定陆地/水域边界。目标选择和每一步移动都受边界及网格余量限制；水生动物还受深度约束。演示状态只存在于该World，不写入玩家存档。

2026-10-01用户速度增量：全部14种动物基础快速逃离为玩家基础疾跑的105%（当前630对600厘米/秒）。逃离、起步、收步使用同一逃离速度上限，玩家疾跑技能加成同倍率作用于该上限。步态播放以当前真实位移除以原配对参考速度，上限覆盖该逃离速度需要的倍率；原骨架与动作文件保持配对。缓步和自然活动不使用逃离倍率。
