# CT-004 · 020展示与配套玩法接口

UI只通过Gameplay组件公开查询与命令、现有HUD仓储/对话接口、SaveSubsystem存读档接口操作。Gameplay组件拥有角色状态、技能、任务、探索和装备状态；UI只拥有当前页、选中项、滚动、缩放和输入草稿。

Resources/UI下保存视觉布局、主题、美术和字体。Resources/Data/gameplay.json保存内容与调参；现有类型下的追加内容通过稳定ID、配置与公开命令接入；新增交互类型仍需代码。动态列表和若干页面细部坐标目前在Compose函数中。ID稳定，用于存档关联。

同一FHearthwardWorldSave加入可选Gameplay JSON字段，旧schema1档缺字段时，已启用020会话将其迁移为初始Gameplay状态，初始装备/补给放入共享仓储，不丢失既有背包/仓储/知识；Legacy夹具继续保持未启用的旧语义。读取前验证新增状态，成功后随世界一次恢复；读取失败不得修改当前世界。

装备引用必须是个人库存中实际拥有的物品；消费与转移后重新校验。任务条件源于真实库存变化、操作事件、发现与技能，不由UI页面访问直接判定完成。奖励已领取状态与经验、技能、探索同边界保存。

伙伴等待/跟随/进攻与自定义地图标记同快照保存；药品、投掷和修理均消费真实库存。图鉴以发现、交流、任务及击败事件解锁，收集历史以collected:<item-id>事件记录，取得后消费或入库不抹去历史。
