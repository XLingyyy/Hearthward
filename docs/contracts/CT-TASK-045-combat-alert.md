# CT-TASK-045｜动作命中与警戒契约

APPROVED，Owner／Reviewer XLingyyy于2026-09-26批准D1—D6并授权045实现。D4统一为3秒、静音、零耐力；[设计](../design/DSGN-R06-combat-stealth.md)为规则依据。

## 权威与接口

- Character将F／R交给同一个Combat.Execute；Combat组件持有动作、开始A时刻、action_id和epoch。普通攻击开始扣费，投射释放扣库存和耐力，处决无费用。
- 动作开始占用目标，敌人CanAct拒绝反抗。取消释放占用；3秒完成重复核验目标、背后距离、遮挡和重型门槛，再提交一次defeat。过程不发声音或听觉事件。
- 活跃窗口由A时钟跨段计算，武器扫掠按最小子步采样并按action_id/目标去重，实际碰撞决定命中。取消、终态、换档关闭旧窗口。
- CombatTarget保存稳定Id、Region、Generation、生命、部位耐久和观察者记忆；骨骼映射或四部位碰撞体必须由内容明确配置。受保护目标和兄弟不走敌人伤害结算。
- 玩家战斗命中先闪避／盾，再命中部位护甲和独立减伤，最后交044生存组件。环境伤害继续直接走生存组件，不进入盾或闪避。
- 现有strong技能数据沿用开发配表；随机击晕统一等效清敌。正式装备和实例耐久留给047，不猜新武器伤害与弹速。

## 感知与空间

每名观察者分别记录player／brother发现条、最后已知位置和当前目击；HUD显示对player的最大值。无视线时AI只搜索记忆位置。CombatRegion提供区域和亮度标签，AI导航目标受区域边界限制；旧开发敌人保留显式PrototypeEncounter边界，不往自然地图生成测试敌人。

尸体报警剩余3A秒，成功后写该尸体本区域传播标记并设alarmUntilA=now+120。同一尸体不续期；持续战斗不被期限清除。击晕使用同一永久尸体，搬运不再发奖励。感应只返回范围内已加载活敌，数据不写伙伴知识快照。

## 保存与旅行

外层schema5和Gameplay JSON version1保持；新增可选字符串字段combat，内部Version=1。缺字段旧档采用无新增警戒／冷却的初始状态，原有死敌仍保持死亡。快照保存目标变换、生命、代次、发现量、最后已知位置、传播标记、报警剩余与截止时刻、离区时长、感应、弩装填和可回收落地箭。

未结束战斗动作、搬尸、结算中、飞行投射物拒绝安全保存；自动保存保持延后。读档释放占用／搬运、取消动作和锁定，清理旧弹体，再按新epoch恢复状态。旅行成功后取消动作和搬运；不撤销已经完成的清敌或传播。
