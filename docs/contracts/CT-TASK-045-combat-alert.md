## 权威职责

| 模块 | 唯一职责 | 复用边界 |
|---|---|---|
| Character／动作执行器 | 输入意图、动作阶段、费用预留、取消窗口 | 复用现有角色和动画，不从Notify直接无条件扣血 |
| 碰撞／装备 | 扫掠、弹体、部位映射、实际装备与耐久 | 现有Inventory仍是物品权威；047决定实例ID及配表 |
| 伤害结算 | 友敌过滤→闪避→格挡→部位防御→生存 | 玩家／弟弟交给044；敌人清除交给043身份与代次 |
| 感知／警戒 | 每观察者发现量、已知位置、分区传播 | 模型只读权限内信息，不能决定命中或全图位置 |
| Save／Clock | A边界、epoch、快照与原子恢复 | 复用现有时钟和保存；禁止新建第二个倒地计时器 |

## 请求与提交候选

动作请求携带调用者稳定ID、action_id、epoch、语义输入与装备版本；返回Accepted／Rejected及具体原因（NO_STAMINA、WRONG_EQUIPMENT、OUT_OF_RANGE、BLOCKED、BAD_PHASE、TARGET_INVALID、STALE_EPOCH）。客户端或模型不能提交“已命中”作为权威事实。

命中键为(epoch, action_id, hit_segment, target_id, life_generation)。同段同目标一次；墙／盾先截断，不用Actor容器遍历顺序猜最近命中。跨帧按前一采样到本次位置扫掠；同刻独立攻击按稳定ID排序。Notify与动作时钟只触发同一状态机迁移，不能各自扣费。中断／卸装／死亡／回档关闭有效窗，即使动画结束回调缺失也不保留伤害窗。

生存期限与致死事件沿用044优先级。动作开始扣普通攻击耐力；投射释放原子扣物和费用；潜入预留费用、完成重新校验后扣除。重复完成返回既有结果，不重复扣费、发物或defeat。不得在结算中重入保存或发布半完成状态；失败不留下半扣资源。

装备损耗在命中结算内处理。待047实例语义明确后再选择存档字段；本单不把当前按类型耐久偷偷批准为正式方案。若动作进入后装备身份改变，取消旧动作，不将旧武器命中套到新武器。

## 警戒状态候选

观察者状态：Patrol→Suspicious→Combat→Search→Patrol。视觉发现条、最后已知位置和当前目击是不同字段；Search不能读取目标持续实时位置。尸体报警为独立3秒动作，可被中断；成功后当前区域登记(body_id, life_generation)，更新alarmUntilA。区域警戒超时只提出结束请求，仍有目击／战斗则保持。

尸体有原敌人稳定ID／生命代次、变换、搬运者、藏匿状态、各区已传播标记；尸体和战利品分开，移动不得复制奖励。感应结果仅供主角临时表现，不写伙伴知识快照，不使攻击目标无条件合法。

## 保存与旅行边界

043／044安全规则优先：战斗、倒地、溺水、事务中拒绝保存；将未结束攻击／投射释放事务视为不稳定边界，延后自动保存。潜入非战斗安全节点需同档记录发现条、最后已知位置、未结束广播剩余A、分区警戒截止A、尸体传播标记、离区计时和感应剩余／冷却；不允许读档把可疑状态清零。未完成尸体搬运在安全保存前放下并稳定变换，避免依赖临时Actor指针。Schema迁移在实现时单独列出，旧档缺尸体数据不得推导额外战利品。

旅行先按043允许条件处理，成功后取消攻击／锁定／搬运并释放预留；不能用取消回调撤销已成功传播的警报或恢复死敌。旧epoch的命中／广播／投射回调全部拒绝，无离线推进。
