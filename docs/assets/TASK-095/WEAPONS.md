# 首线武器制作与持握

方向沿用DSGN-004：朴素实用，保留原角色比例、骨架和战斗规则。原TASK-070短刃98,299面、长矛96,818面，高于框架手持武器20,000面预算；旧包保留，新运行候选使用本地Blender原创几何。

制作源为 `art_source/TASK-095/Weapons-Practical.blend` 和同目录 `author_weapons.py`。源用米，握点位于原点，刃尖/枪尖及弩射击方向为+Z。导出使用实际厘米坐标，UE导入后核对尺寸。五件均无开边；三角面为短刃2,122、长刃2,986、长矛2,178、战斧2,864、弩1,512。

顶点RGB保存基础颜色，Alpha区分金属与木材/皮革；UE材质的MetalFinish参数按实际物品stage选择石制或金属表面。暂复用同系轮廓，不把材质变化称为逐等级独立模型。最初按combatClass制作的钝器锤头经物品名称和toolKind核对后弃用，blunt_2/3使用战斧。没有改配表名称、工具用途或伤害。

右手握点从原骨架拇指与中指参考位置校准；弓使用左手。组件绝对缩放保留武器真实厘米尺寸，防止原骨架100倍根缩放传入。实际装备GUID、耐久、近远程模式、生存状态和施救状态决定显示。原石斧组件与物理刃扫掠保留；新组件不参与碰撞或增加伤害。

接入遵循[Epic骨骼挂接与Socket约定](https://dev.epicgames.com/documentation/unreal-engine/skeletal-mesh-sockets-in-unreal-engine)，偏移保存在角色组件，未修改共享骨架包。制作阶段的几何预览与实机持握/动作验收分别登记于QA报告。

长枪新增原创双手突刺源 `Hero-Spear.blend` / `author_spear_motion.py`，沿用原骨架的FBX根缩放。动作归一化准备/有效/恢复分界为0.6/0.8/1；运行时按原轻击0.25/0.12/0.38秒及重击0.50/0.15/0.55秒分别采样。动画只读Combat.Elapsed，不创建命中或消耗事件。
