# 兄弟倒地与救援动作

CMU 113_08提供躺下与起身动捕，来源、许可及所需署名见[制作源说明](../../../art_source/TASK-095/cmu/README.md)。使用现有GameFactory world_delta与cmu_bvh/ue5_mannequin骨骼映射重定向；施救动作另行编排蹲下、伸手支撑与站起姿势。原角色几何和贴图权利不由动捕许可覆盖。

每个角色使用Down（1.2秒）、GetUp（5秒）、Rescue（5秒）三个独立AnimSequence。Hero和Brother分别绑定各自原Skeleton。被救者的起身动作和施救者动作读取同一实际救援进度；动画不结算治疗。自动靠近方案见[批准记录](RESCUE_APPROACH.md)。

原兄弟FBX骨架根缩放为100。初版误用新射手的厘米归一化导出，动画根缩放变成1；关节坐标仍正确，但蒙皮收缩为碎片。修正为米制场景与FBX_SCALE_NONE，保留既有根缩放；新增原生根/头部继承缩放回归检查。未修改原网格或骨架以掩盖问题。

准确六个UE包及两份可编辑Blend在写入前取得LFS锁，锁保留到集成。UE导入、定向原生和双人实机分别记录，不以程序状态通过替代画面验收。
