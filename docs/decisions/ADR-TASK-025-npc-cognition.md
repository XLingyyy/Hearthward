# ADR-TASK-025：有来源的认知与有界多轮对话

2026-09-19；技术实现范围由用户“025自主研发再交付”授权。沿用GDD与DSGN-001；不替R18/R20/R21作全面玩法裁定。

## 研究与取舍

- [Generative Agents (2023)](https://arxiv.org/abs/2304.03442)提示观察、记忆检索与规划需要独立建模。本项目采用有来源的记录与相关性检索，不引入额外反思推理或自主生活模拟。
- [Writing effective tools (2025)](https://www.anthropic.com/engineering/writing-tools-for-agents)强调有明确用途的能力接口与精简上下文。本单直接描述现有采集执行契约，未接通的制作/维修不给模型执行入口。
- [Demystifying evals (2026)](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)将轨迹与最终状态分开评估。本项目保存原始模型结果，并用真实库存、执行阶段和回档后状态判定行为，不以台词代替执行证据。

## 组织与接口

NPC认知由AI模块拥有，保存模块只承载快照。新增UE反射结构保存玩家记录、最后亲见营地库存/时间及待澄清对话。旧档缺字段默认空认知，原始Knowledge日志保持兼容但不作为可撤销记忆的检索源。

记录只由玩家显式创建/编辑/撤销，来源固定为玩家；陈述未经核实，偏好/约定也不能改写角色身份、世界或能力权限。模型不能调用写记忆接口。撤销后排除检索，同时清空旧澄清并废止进行中的回复，防止旧上下文再次引用。

营地观察仅在弟弟实际处于既有营地观察半径内更新；离开后保留最后一次观察并标明过期。时间使用世界活动秒，随存档回退。新周目清空，回档恢复同一节点，不重放未来日志。

澄清保留完整用户原话和NPC问题，受上下文预算限制。超预算明确要求重述，不静默截断约束。实际collect/cancel/refuse结束待澄清；闲聊不执行旧提议。模型回复仍以epoch/请求代次和交流距离复核。UE校验实际物品/步骤/安全与库存；不承诺任意自然语言约定都有确定性约束执行器。

## 本单边界

词项/中文二元片段检索，无Embedding和自动反思；选择近期与相关的玩家陈述，全部有效约定保留在有界上下文内。固定知识继续使用现有初始知识库。新的原型容量与预算为工程配置，不是正式玩法数值。

不实现额外动作执行器、多NPC调度、全球建议生成、自主聊天、完整危险感知或所有生产系统。研究结论与实际通过场景在交接填写，不能以此ADR冒充验证完成。
