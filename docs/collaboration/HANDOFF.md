# 会话与任务交接

模板：[handoff.md](../templates/handoff.md)。保存为 `docs/handoffs/TASK-xxx.md`。
这是任务分支上的最新可续做快照，不是每日大篇工作总结。

至少记：实际代码SHA、分支、尚未提交变动、已完成／未完成、测试命令与结果、
环境、复现入口、设计／契约阻塞、资产锁、下一步和回滚办法。
会话接手先读目标分支，不在main误读未合并任务的旧状态。

不保存隐藏推理、完整聊天、敏感变量或原始长日志。只记录可供下一个人验证的事实、
必要决策与失败尝试。更新交接后又改功能时，重新核对证据。

上次测试绑定代码SHA；文档提交随后生成新SHA时，用tested_commit指向实际测过代码，
不要尝试在同一提交文件中填该提交自身的未知哈希。最终main验收在Issue／报告绑定最终SHA。
