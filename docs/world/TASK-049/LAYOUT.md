## 依据与地形边界

采用026 `Reserve.json` 中新营地(-980,-750)、故乡(1090,450)，不是早期自然图的旧故乡坐标。PlayerStart已有记录约(-976,-752,161.95)m，仅营地出生点有历史运行证据。远端地形、碰撞和导航尚未为本单验证；高度一律由正式施工时地表trace与NavMesh投射确定。

原026的`routes.json`是1207点闭环，营地正向至故乡最近点约6890m且途中有折返。本稿不把这条历史环线默认用作任务导航，改为候选营地→旧路岔口→矿源→渡口→山脊望点→前哨→故乡河门的连续折线。它是需审查地形的施工走廊，未证明已铺路。初稿横跨高度变化可能需要绕行，必须实走后更新路径，不借直线距离宣称7分钟已达标。

入口走廊至少4m宽；可选潜行旁路至少2m净宽；营救路线保持双向步行和3m转弯空间。所有边界都要有步行坡道或平地入口，不把门锁、攀墙、游泳或跳崖设为必经条件。这些为本轮候选关卡尺寸，不重设角色碰撞或移动参数。地图必经路线施工若需改026共享地形，先协调该任务写者及LFS锁。

## 第一切片与有效发现

近郊救援 `slice_rescue` 位于(-380,-845)m，在主路约650m处。三名野外普通巡哨独立ID，不计入故乡80；在目标周围70×40m回路巡逻，拟留至少35m侧向避让空间及植被／实体遮挡。35m不作为“必定安全”的判定，仍按实际045感知、视线和光照验收。被救者安全等待区内禁止刷新敌人，延后生成时保持同一代次，不能额外领奖。

主路节点功能：route_fork选择主路／救援旁路；route_mine确认矿产来源；route_ford决定站点激活与撤离；route_ridge侦察；route_watch观察敌占轮廓；home_entry选择河门／侧路。普通木石采点不计为这些有效发现。候选点间距与3.5m/s行走预算见[检查报告](../../qa/TASK-049/REPORT.md)；真实绕行、战斗、视线与叙事停留未计。

第一切片在近郊救援后原路回营，完成工作台I、人口20→21和2阶升阶，不要求进入故乡。补给预算沿046：至少120木＋24石用于工作台及升阶；武器、药物和食物另需真实来源。048已能生成有限资源，但本单未对这条候选路线重新运行供给与争用验证。

## 传送、救援与安全阶段

设置营地、渡口、故乡三个站点。候选30m发现、2.4m明确交互激活；故乡站在永久夺回后才可激活。站点状态显示未发现／已发现未激活／可用，选中任务才叠加精确目标。激活不承诺周边永久无敌；传送集合、敌血、兄弟状态沿043。野外救援者不参与兄弟战斗传送，持续在合法集合／等待状态。

故乡中心的第二营地与四区使用同一世界坐标。敌占→安全仅切换合法场景表现和交互：禁用敌军产生、保留任务物、转换未救族人对白、启用046赠送设施，不换新地图、不复制库存。保护人物留在原区生活或撤离到同区安全角，不消耗普通人口指标。敌占阶段毁坏的装饰不追加重建费用。
