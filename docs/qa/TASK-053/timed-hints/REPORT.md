# TASK-053 · HUD提示两秒自动消失

2026-10-03。Owner XLingyyy；分支 `codex/TASK-053-title-wheel`，HEAD `4db5789184fe38e041d62a1e68c8517338ea0b01`。本轮用户要求截图中的操作提示出现两秒后自然消失，沿用项目内统一测试端。代码与此前UI增量仍为未提交工作。

## 实现

右侧操作结果原先每次HUD刷新都从各组件读取最后一条文字，旧结果没有有效期。现在按来源分别记录提示事件及显示期限；首次显示后两秒截止，最后0.35秒连续淡出，文字阴影同时淡出。绘制时直接检查期限，避免0.2秒刷新间隔延长实际显示时间。

同一操作再次产生相同文字也会记录新事件、重新显示两秒。界面刷新、另一个来源出现提示、暂停及返回HUD均不重启旧期限。建造放置的逐帧校验只在文字变化时记录新事件，避免相同校验结果持续续期。战斗、用药、攀越等进行中的实时状态及生命条保持原有显示；读档时清理过时的瞬时提示，不改变存档格式或玩法数值。
