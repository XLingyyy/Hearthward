## 实际地图来源

正常新游戏序章出生点实测XY为 `(92000,53500)` 厘米，即 `(920,535)` 米；固定半径250米。读取当前游戏World的63,001个地面碰撞高度点，2米间距、251×251采样。建筑、树木、岩石来自当前加载Actor及实例位置，水面来自当前Actor和对应原始GLB的投影三角形，并以实际Actor包围盒核验轴向、位置和缩放。四件水面模型边界的最大差为约0.00002米；这个数字只描述模型边界对齐，地形精度仍受2米采样限制。

## 位置和显示

地图与高空相机同向：世界+X向右、+Y向下。横纵采用同一个比例，850设计像素对应500米，缩放及平移共同作用于底图、区域名和人物。Z不参与平面定位。红、蓝火苗的脚部锚点分别是玩家与弟弟的真实XY；接近时火舌向两侧倾斜以辨认，不偏移锚点。NativeTick更新位置并使变动重新绘制。

圆形可见性使用真实XY欧氏距离，范围固定，不随角色移动或探索记录扩展；无弟弟Actor或人物位于250米之外时隐藏对应标记。底图与最终绘制遮罩共同覆盖范围外像素，缩放、平移及超宽显示保持黑雾。地图删除原导航、侧栏、探索进度、图例、任务／传送说明、POI及操作文字，只显示故乡、草原、坡地、河谷、湖岸。键盘M／Esc返回、滚轮缩放与方向键平移保留。
