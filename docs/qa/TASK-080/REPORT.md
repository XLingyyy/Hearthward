## 实现

既有任务的地点指引此前用于地图页，HUD没有世界投影标点。本轮复用当前追踪任务、`QuestLocation`和`LocationPosition`：

- 金色菱形标记锚定目标上方，显示直线距离和地点名称；墙体遮挡时仍可见。
- 视野外／背后目标夹在画面安全边缘，并附指向外侧的箭头。相机转动时逐帧更新。
- 根据实际视口与Widget尺寸换算投影，不把固定设计画布坐标直接当屏幕像素。
- 沿用任务阶段的目标地点切换；无追踪、不可用任务、已完成步骤或已领取任务不残留目标。菜单页面隐藏世界指引。

采用Epic官方的[世界坐标投影到屏幕](https://dev.epicgames.com/documentation/unreal-engine/BlueprintAPI/Camera/ProjectWorldtoScreen?lang=en-US)接口。图形由Slate绘制，未增加纹理或第三方依赖。距离是直线距离；此次没有自动寻路、地面路线光带或室内逐拐点导航。
