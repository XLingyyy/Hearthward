# 更新提示与存档兼容

本地分支 fix/legacy-camp-save，基线 9058ee2978f87cafa02e13666ebd0d96b81cd2f2；版本 0.2.0-preview.20260930.1。用户授权从根本修复旧档冲突，并选择由游戏打开 GitHub 正式发布页、玩家手动下载安装。未提交、推送或发布。本报告取代前次旧营地修复报告对当前版本验收状态的描述。

## 行为

- 主菜单通过固定仓库的 releases/latest 接口异步检查一次，支持手动重试，8秒超时。发现更高版本显示“存在新版本，请同步更新”。按钮只打开 https://github.com/XLingyyy/Hearthward/releases，不自动下载或执行文件，不上传存档。网络失败、限流与无正式版本均不阻断离线游玩。
- 修复原始schema1—5缺少CampEconomy的旧营地迁移，沿既有旧建筑恢复路径保留建筑；旧历史实付材料账本为零，不能凭空拆返材料。继续拒绝损坏的非空营地记录。
- 旧文件 `Saved/SaveGames/HearthwardPrototype/pool.hws` 只读导入；新版保存在同目录的 `Compatible-v8/pool.hws`，并写入WriterVersion。旧程序仍只能读写旧池，不会覆盖新版。新版池一旦存在，不再自动合并旧程序之后的游玩；不能在两条时间线之间自动无损合并。
- 兼容进度保留，包括存档点标识、物品、仓储、建筑、技能与已知配方。冲突预览只在内存中生成，逐项列出存档点及对应内容。当前可识别已移除的物品、装备、建筑及关联队列、技能及依赖技能、配方，以及超出当前上限的经验。清理建筑关联队列时明确提示已投入材料不返还。
- 玩家读完分页并确认后，重新检查文件指纹与冲突清单，备份原件并校验备份字节，再写入完整校验通过的候选池；取消、预览过期、备份失败均不覆盖原文件。其余未知损坏、新格式或更高版本档禁止自动删除，说明相关领域并提供发布页与存档目录入口。
- 程序升级/清理备份位于源文件旁的Backups，文件名带内容指纹；同版本日常自动保存不持续产生升级备份。安装脚本不打包Saved目录，不删除玩家存档。

## 后续正式发行

每次发行同时递增HearthwardVersion::Current和安装脚本AppVersion。正式GitHub Release使用严格三段版本标签（例如v0.2.0），设置为正式发布并提供对应Windows包；预发布不会被正式版latest检查发现。版本号必须与包内版本一致且高于旧版。现有不带更新检查的旧可执行文件不能远程自行增加功能，玩家必须先手动换用本版一次。

这里保证当前已支持迁移的存档字段，并不保证任意模组、手工损坏数据或未来任意规则变化都能自动合并。后续内容改变时仍须追加迁移规则与冲突说明；无法安全解释的记录继续保留原件，不做整体清空。
