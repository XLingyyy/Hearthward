## 实测结果与修复

初轮接口创建和销毁成功，但游戏截图没有粒子，判为视觉失败。隔离试验移除材质年龄因子后火烟可见；引擎轻量模板输出变量和 ScaleColor 实现确认 NormalizedAge 供模块内部使用，没有向材质输出该属性。原材质的 ParticleRelativeTime 淡入将透明度乘零。改用 ScaleColor 的生命周期曲线输出粒子颜色 Alpha 后，重新启动编辑器与 PIE，火焰和烟均可见。

最终 80 帧覆盖启动、稳定、停止与消散；停止后末段无残留，销毁后标记效果 Actor 为 0。日志包含截图命令 `Shot` 的控制台查找性能警告；未以零警告报告本轮。这里只验证隔离效果生命周期，未验证正式地图的反复读档、离场、视线遮挡、Cook 或性能预算。
