## 冻结独立集首次结果

V2 在30题上原始20/30，受限10/13，明确E2E 7/17，支持执行夹具的10题中2题实际执行通过，白得物品0。六个多轮样本均实际发送前轮，原始正确要求前后轮同时符合预期；部分末轮正确但首轮未澄清的样本仍计失败。报告为 `model/v2-holdout30-vulkan.json`，模型和提示在运行后未修改。

除模型误解外，独立集暴露既有执行校验的保守拒绝：collect 的原话正向采集词检查不接受“砍”；fetch 的所有者文字检查接受“你背包”，不接受“你自己的背包”或“你的背包”；多轮把非标准短语保留为未解决条件后，补充数量也未清除该短语。随后单独修复前两处：木材采集接受“砍/砍伐”，背包所有者接受“你的/你自己的/弟弟的背包”。原有否定、已取得物资、未知来源与错误所有者校验保留；增加真实 StageCandidate 与契约回归。多轮任意未解决短语仍保守保留，尚未修复。原60题与独立集首次成绩不重算、不回填；这两处修复不能视为模型原始语义分数提高。
