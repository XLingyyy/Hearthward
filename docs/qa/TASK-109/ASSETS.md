# 营地动作与首线道具预算

## 实际制作

从 Quaternius Universal Animation Library 免费 Standard 的 CC0 原始动作重定向到现有 Brother 骨架，导入 `A_Brother_SeatedIdle`（1.6667 秒）和 `A_Brother_SeatedTalk`（2.9333 秒）两个循环。来源、原许可、原始 GLB 和重定向脚本保存在 `art_source/TASK-109`。SitDown / StandUp 只在制作目录中生成，未作为当前游戏功能接入。

初始营地的合法用餐事实驱动两位空闲族人的坐姿；工作分配优先于坐姿。修正座位朝向轴，使角色位置匹配既有两把椅子。第二营地真实用餐后，既有居民在餐桌旁使用坐姿交谈，不增加人口。动画加入 Cook 范围。

实际窗口从 TASK-108 隔离 QA 旧档的副本继续，在第二营地夜间观察到居民坐在对应椅子上，脚接近地面、手臂在桌前交谈。该存档是历史测试夹具，不能计为正常完整流程完成。最终族人岗位分配与表现原生回归通过；M1 坐椅接触、完整工作切换动画仍待正常流程查看。

屏幕阈值为 1 / 0.18 / 0.07；LOD0 的三角形、顶点、材质槽以及斧头 Grip / BladeBase / BladeTip 插槽均与修改前一致。原件备份在 `E:/HearthwardQA/TASK-109/prop-lods/original`；修改结果为同目录 `prop-lods.json`。石斧使用已有本人锁，木椅在修改前取得本人 LFS 锁。

同机位强制 LOD0 / LOD1 / LOD2、近远两个距离的 UE 对照在 `E:/HearthwardQA/TASK-109/lod-review-lit`。逐张检查近档三种 LOD 和远档 LOD0 / LOD2，未见明显轮廓缺失，远档整体识别保持。隔离灯光只用于比较；材质暗部仍较深，不据此宣称完成全部材质或移动跳变验收。首次无专用灯光的暗图保留在 `lod-review`，不作为质量通过证据。

两件道具通过材质依赖实际查到各三张 2048×2048 纹理：Color / Normal / Roughness；均允许流送、LOD bias 为 0，压缩分别为 Default / Normalmap / Masks。未发现必须立即降分辨率的证据，因此保留纹理和全局画质。

其他首件只读测量：工作台 1,708 三角面 / 3 材质，卧室木构 4,320 / 2，河门 4,428 / 2；未对这些低成本网格追加减面。数量来自 `asset-probe/asset-budget.json`。本报告不以面数下降代替帧率实测。
