## 原选面的位置和法线

原候选三角 `[4265,4268,4258]` 三点均真实 dominant `hand_r`；rigid hand 坐标质心 `(-1.928832,-4.132910,2.351563)`cm。骨名只能确定它属于手，无法独立区别掌与背。

UE 本机 `StaticMeshOperations.cpp:45–48` 明确使用左手坐标及逆序叉乘 `cross(D2,D1)`。采用这个约定，原面法线为 `(-.824998,-.212504,+.523661)`。由实际 index_01 / pinky_01 / thumb_01 的骨位置构成手部参考面，并将方向朝实际弯曲指尖，得到参考掌侧法线 `(-.462342,-.126325,+.877657)`；原面的点积为 +.868。对照三角 `[8418,8416,8415]` 位于 rigid Z=-3.223cm，UE 约定法线 `(+.125,+.063,-.990)`，同参考方向点积 -.935。

证据支持原面处于掌侧偏侧位置，未支持它是手背。此为实际几何/骨参考方向的判定，没有新采 imported shading TangentZ，也未把一个三角质心声明为唯一解剖掌心。

原掌面至最近中/无名指三角 `[7564,7566,7563]` 的 2.369292cm 是两处真实表面之间的局部距离。它没有证明整条柄轴经过的是同样宽的空隙。实际相邻掌面、拇指面仍穿入柄；按四个末节手指中心推得的方向只能作为已测候选轴，不能从其中一对表面推导整个夹持通道。

## 一个保留长度/刃/socket的候选

只保留最大已测可分离系数 .15 作为 Root 无保存实拍候选。完整参数为 `stone-axe-local-handle-section-candidate.json`；10,446 个实际 source vertex 的原 ID、原位置和新位置为 `stone-axe-local-section-candidate-vertices.json`。拓扑和 UV 对应没有重建。

保持实际 world scale .7、已实拍 minimum-align 四元数。将 unchanged Grip 放到实际 hand_r local `(-.0168871707,-.0318921930,.0122154793)`，对应 rigid hand `(-3.10584775,-5.86553586,2.24664234)`cm；相对旧候选平移 1.346291cm。目标依据当前固定轴的真实皮肤投影空隙，未搜索新欧拉角。

局部几何公式：

```text
d = (-.5526946739,.2612031745,.7913921272)    // 真实下柄两截面中心之间的轴
s = dot(P-Grip,d)
r = P-Grip-s*d
w = smoothstep((s+20)/8) * smoothstep((26-s)/10) * smoothstep(-P.z/12.5)
P' = P - .85*w*r
```

每个 smoothstep 的自变量先 clamp 到 [0,1]。核心轴段 s[-12,+16]cm，支持范围 s[-20,+26]cm，两端一阶导数平滑归零；原 raw Z[-12.5,0] 上端另渐变回原形，raw Z>=0 完全不动。径向偏移和原柄的径向曲度一起收向实测轴，公式没有隐藏轴向重缩放。

每个实际顶点沿 d 的坐标变化最大 7.77e-15cm。实际轴向全包络长度前后都是 83.876989cm；Grip、BladeBase、BladeTip 三个 authored socket 的局部位置变化全为 0。原 .7 的实际刃弦 25.462938cm、Grip→BladeTip65.407854cm保留。轴向平移只改变绑定位置，没有缩短实体工具。

当前 Grip 原截面沿掌外/横向为 7.602511×6.137350cm，候选为 **1.140376×.920602cm**。这是85%径向收细，需要真实图片判断形状、包裹材质和细柄视觉。候选保留全头部，过细柄与大头部的比例可能不合适；若视觉不能接受，后续应修真实握姿开合，不能宣称这个数学候选已完成产品验收。
