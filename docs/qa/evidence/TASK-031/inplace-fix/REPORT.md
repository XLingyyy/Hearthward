# TASK-031 动画位移回归修复

2026-09-24，用户复测发现模型超前于胶囊和镜头，动画循环后跳回。修复基线为 `b3ff1753d57300984b55988806424495f08597c6`；本轮完整提交见 tested-revision.json。上一轮仅确认状态切换和关节运动，遗漏连续循环时骨盆相对胶囊的偏移检查；上一轮 PASS 不能证明没有此问题。

## 根因和处理

旧动画的 root 平移恒定，但 pelvis 包含持续前进轨迹。旧主角在实际 PIE 中行走最大离胶囊约 2.87 m，冲刺约 6.61 m；模型轨迹每轮归零，镜头继续跟随胶囊。角色移动速度和镜头参数保持原配置。

用户新提供 `F:/Download/medieval+knight+3d+model (1).zip`，归档为 `Resource/Tripo/主角/medieval+knight+3d+model-with-animations.zip`。已通过 UEClient.import_motion 导入原包八段动作到 `Hero/AnimationV2/SourceTripo`，使用现有新主角骨骼，模型、材质不变。主角运行时全部改用自身动作，攻击/起跳/空中/落地由自身 Chop/Jump 裁切，旧弟弟重定向结果不再驱动主角。

对双方 Walk/Run，在组件空间减去骨盆首尾的水平前进趋势，并将起点对齐参考骨盆的水平位置，再通过 root 旋转和缩放的逆变换写回本地轨道。保留身体上下起伏、步态摆动、关节旋转、root 的轴向和单位缩放；角色与镜头位移由已有 CharacterMovement 控制。只锁 root 无法去掉 pelvis 上的轨迹。脚本每次从未改动的导入原始动作派生，可重复运行。
