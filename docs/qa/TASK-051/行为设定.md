# 14种动物的行为设定

当前制作成果包含雄鹿A、野兔、山羊、雉鸡、猪、狼、黑熊、公羊、母鸡、赤狐、鲤鱼、鲫鱼、鲶鱼和鳗鱼，成套模型与动作保持对应骨架。动物名称沿用户资产目录；模型没有更细的学名鉴定，下表参考同类动物的通用习性安排现有动作，不据此判定模型属于参考文献中的具体亚种。

| 动物 | 无威胁时，与缓步／缓游交替的活动 | 逃离形式 | 同类习性参考 |
|---|---|---|---|
| 雄鹿A | 低头采食，抬头张望，卧下休息与起身 | 起跑后奔驰 | [ADW：鹿的采食与休息](https://animaldiversity.org/accounts/Cervus_elaphus/) |
| 野兔 | 啃食，整理毛发，竖耳观察，低伏休息 | 连续快速跃跑 | [ADW：野兔觅食、低伏与逃离](https://animaldiversity.org/accounts/Lepus_europaeus/) |
| 山羊 | 采食，咀嚼，张望浏览，卧休 | 小幅警觉后跑开 | [ADW：山羊采食草和灌木](https://animaldiversity.org/accounts/Capra_hircus/) |
| 雉鸡 | 地面啄食与刨食，理羽抖羽，沙浴 | 扑翼快跑 | [ADW：雉鸡地面觅食与避险](https://animaldiversity.org/accounts/Phasianus_colchicus/) |
| 猪 | 低头嗅地拱食，进食，卧休 | 起步后跑开 | [ADW：猪的食物与嗅觉](https://animaldiversity.org/accounts/Sus_scrofa/) |
| 狼 | 嗅地探索，卧休，抬头嚎叫姿态 | 起跑后奔驰 | [ADW：狼的嗅觉、移动与嚎叫](https://animaldiversity.org/accounts/Canis_lupus/) |
| 黑熊 | 嗅探觅食，挖掘姿态，短暂立起嗅探，卧休 | 沉重起步后跑开 | [ADW：黑熊觅食与感知](https://animaldiversity.org/accounts/Ursus_americanus/) |
| 公羊 | 采食，咀嚼反刍姿态，卧休 | 短距离跑开 | [ADW：羊采食、反刍与休息交替](https://animaldiversity.org/accounts/Ovis_aries/) |
| 母鸡 | 啄食刨食，理羽抖羽，沙浴，蹲卧休息 | 扑翼快跑 | [ADW：鸡的地面食物](https://animaldiversity.org/accounts/Gallus_gallus/)；清理和沙浴沿现有动作方案 |
| 赤狐 | 嗅探，小幅扑跃探索，整理毛发，蜷卧休息 | 听觉警觉后跑开 | [ADW：赤狐感知与扑跃觅食](https://animaldiversity.org/accounts/Vulpes_vulpes/) |
| 鲤鱼 | 缓游，觅食吸食姿态，减速滑行或悬停 | 快速摆尾游离 | [ADW：鲤鱼底部觅食](https://animaldiversity.org/accounts/Cyprinus_carpio/) |
| 鲫鱼 | 缓游，觅食姿态，暂停滑行 | 快速摆尾游离 | 沿当前鲫鱼动作方案，使用通用淡水鱼展示循环 |
| 鲶鱼 | 缓游，低位悬停，触须探索与觅食姿态 | 快速游离 | [ADW：同类鲶鱼的感知与活动](https://animaldiversity.org/accounts/Silurus_glanis/) |
| 鳗鱼 | 低幅波动游动，悬停，避藏与觅食姿态 | 较快的全身波动游离 | [Aquatic Sciences：鳗鱼栖息地与隐蔽选择](https://link.springer.com/article/10.1007/s00027-024-01125-3) |

这些活动是展示姿态与日常运动循环，嗅探、挖掘、扑跃、觅食和沙浴不生成资源，也不产生跨物种捕食战斗。狼与熊同样按本轮要求，在玩家或弟弟靠近时逃离。未设置现实昼夜作息、季节繁殖或群体生态；14只各一只的演示与正常大地图种养、钓鱼收益规则分别由各自系统负责。

平静时先短暂静候，再在出生点附近选择区域内目标，以原动作参考速度缓行6–11秒或到达目标，收步后执行一组物种活动。循环依次轮换，不会一直抽中同一行为；采食循环通常保持6–10秒，卧休通常10–18秒，这些都是方便实机检查的可调时长。

距离最近且仍存活的玩家或弟弟进入该物种感知半径时，中断自然活动并警觉／起身、起跑、快速逃离。检测半径为4–11米（鱼类3.5–4米）；持续感知威胁，超出1.35倍半径且平静3秒后才收步恢复自然活动。逃离目标每0.3秒重选，候选方向留在区域内。边界不足时转向或停下警觉。

按本次追赶要求，14种动物（包括4种水生动物）的基础快速逃离速度统一为630厘米/秒；玩家基础Shift疾跑为600厘米/秒，速度优势5%，同向直线追赶每10秒多拉开约3米。玩家疾跑技能倍率同样乘到动物逃离速度，两个疾跑技能满级时玩家708、动物743.4厘米/秒；不会按追赶距离或Shift按下状态突然变速。负重、生存与战斗导致的玩家减速仍沿原规则。这里是本轮游戏速度平衡，不能当作真实物种速度。

非致命伤播放受击并逃离；致命伤清除普通队列，停止水平位移，陆生动物完整播放倒地后保持尸体姿态。鱼类使用挣扎／沉降与静止姿态，沉到允许的池底高度；不会在水中套用四足动物倒地。状态间约0.14秒姿态混合，步行和逃离动作按实测水平速度调播放速率；骨架与身体缩放不随快慢改变。

配对动作的原始参考速度保留，用于按真实位移计算播放倍率；快速逃离不再被1.8倍播放上限截断，允许最高为当前逃离速度与该步态参考速度的比值。缓步、自然行为和骨架比例沿原设定。

全部片段路径、来源SHA256、参考速度、检测距离、自然活动队列在 `Resources/Data/animal_motion.json`。参数表达本轮观察要求，不是现实动物的速度上限或精确行为时刻。

水生动作导出没有标注线速度，配置另保存展示用的缓游25、快速游动180厘米/秒参考值，和提高后的实际逃离速度分开。鲤鱼、鲫鱼、鲶鱼先用Burst短冲起步，再用SwimCruise持续循环；鳗鱼沿用StartWave和UndulateFast循环，避免单次Burst播完后保持末帧滑行。快速游动循环按实际速度提高摆尾频率。
