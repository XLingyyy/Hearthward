# 动物实机检查

在 Windows 文件资源管理器中双击 `E:/AiAgent/XLingGame/Hearthward/scripts/animals/启动动物实机演示.cmd`，等待游戏窗口加载。聊天中的文件链接用于定位文件；如果只打开了脚本预览，请到资源管理器中双击运行。本机使用 UE 5.8.2 的 Development 独立游戏窗口。每次打开都是新的演示，生成14种动物各一只；关闭窗口或 Esc 退出。

2026-10-01已修复启动文件的LF换行解析问题，当前为UTF-8、Windows CRLF换行。`scripts/animals/.gitattributes`固定`.cmd`检出的CRLF，避免后续维护再次变回LF。已通过`.cmd`本身启动并确认游戏显示14种动物，记录见`启动修复.md`。

| 操作 | 键位 | 实际效果 |
|---|---|---|
| 切换动物近景 | F5 | 依次循环14种动物；镜头自动跟随，鱼类切到水下观察 |
| 返回主角 | F1 | WASD 移动、鼠标看向，空格跳跃、Shift疾跑；走近动物观察逃离 |
| 弟弟靠近或等待 | F2 | 弟弟实际步行靠近所选动物；鱼类目标走到池边 |
| 致命伤 | F3 | 对所选动物走真实伤害入口，观察倒地或沉降及死亡保持 |
| 重新检查 | F4 | 14只动物恢复生命、初始位置和自然活动，兄弟回到入口 |
| 退出 | Esc | 关闭演示 |

初始动物分布在44×32米陆地围栏和12×24米、约2米深的水池。选点、每一步位移和身体余量均受范围限制；围栏是范围标记，兄弟可以通过，动物受行为边界约束。受惊逃离遇到边界会转向或停下来警觉。不会因为逃离或受伤穿出区域。水生动物同时限制深度。

建议先按 F5 逐种观察30秒左右，再按 F2 检查弟弟接近后的起步、加速和收步；按 F3 检查致命伤，等动作结束后确认不会继续移动或自动站起。F4 可反复重置。主角靠近检查时用 F1 回到角色，向围栏内走。

快速逃离速度统一为基础6.3米/秒，略高于玩家基础Shift疾跑6米/秒；直线同向跑动时每10秒多拉开约3米。已学习疾跑技能时双方使用相同加成，保留5%的速度优势；负重、严重生存状态等仍沿玩家原有减速规则。区域边界处动物会转向或停步，追赶时可以观察这些实际反应。缓步、缓游和日常行为的节奏沿原设定。

每种动物交替执行自己的自然动作，如采食、嗅探、整理毛羽、卧休、缓游和悬停。要查看平静状态，可让兄弟远离该动物；身处感知距离内会持续警觉或逃离。自然活动和休息会被受惊、受击中断，致命伤优先级最高。

地图路径为 `/Game/Imported/Scenes/animal_demo_20261001/Map/animal_demo_20261001`，启动入口自动指定 `HearthwardAnimalDemoGameMode`。直接用主菜单打开旧自然地图或旧安装版，不会进入此演示。完整自然地图投放与正式发行打包不属于本轮；当前自然动物Actor已接入同一动作组件。

演示使用独立临时档池，地图状态不保存；不会打开或覆盖正常玩家存档。行为时长、检测距离和速度是用于检查动作的游戏参数，可从 `Resources/Data/animal_motion.json` 调整，不能当成现实动物的精确活动时刻。
