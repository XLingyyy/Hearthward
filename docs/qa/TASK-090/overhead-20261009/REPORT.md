# TASK-090 物体上方交互提示与可用性修复

用户要求：提示放在物体上方；领取遗物后以及其他无法交互的状态隐藏提示。

复现：新增真实 Campaign.Interact 领取后检查，在修改前确认世界锚点、领取后 HUD 隐藏、领取后 Campaign 提示隐藏三项断言失败。根因是附近目标查询未过滤已完成事实。

修复：提示在 NativePaint 按实际目标世界位置逐帧投影，文字水平居中；目标移出屏幕或位于镜头背后时不画提示。Campaign 从目标查询移除已领取遗物、已占旗帜、已激活路标和已完成一次性事项；临时未满足前提的操作隐藏提示。通用资源耗尽、工具失效、背包无法接收、烹饪材料不足等状态不显示可操作提示。可重复设施仍显示有效操作，仓储无木材时保留管理入口。自然物原有永久 E 标签停用，统一由此提示呈现。

验证：Task090 定向回归、受影响的 HarvestToolPresentation 与 Resource 测试结果见同目录 JSON。独立正式地图 PIE 在实际遗物旁检查提示，调用真实交互领取后检查提示消失。PIE 位移由测试 API 设置，不代表正常键鼠全路线验收。Editor 构建通过；两个编译写法错误在通过前已修正。启动阶段既有 Condition failed 日志保留在原始结果，不声称进程无任何错误日志。

未变更存档格式、奖励、交互距离。源码绑定候选11的构建快照；候选包正常键鼠流程仍由用户验证。整批此前模型质量、性能、完整路线、视听及二机验收缺口不由本修复覆盖。
