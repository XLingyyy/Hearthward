# TASK-112—133 本地候选检查路线

当前工作分支 `codex/TASK-112-round2-foundation`。本轮改动未提交、合并或正式发行；任务是否通过以各 REPORT 和 CASE_MATRIX 的实际结果为准。

## 正常操作

默认 E 交互，X 切换伙伴跟随，M 打开地图。独立游戏中 Esc 打开暂停；编辑器 PIE 中 Esc 可能直接结束运行。自定义键位以设置及屏幕提示为准。

1. 从正常新游戏完成序章撤离，或继续自己的兼容检查点。先保存可回退节点。
2. 营地靠近工匠交谈，开始“把工具放回哪里”。识药的族人在旧药圃尚未发现时保留提示；守望者的结尾需要原有故乡胜利条件。
3. 到工坊旧物匣所在区域。观察高台射手、掩体和服务门，分别尝试正面与侧路。悬片声源只会引来附近最多两名未确认目标的敌人；不会清除敌军或自动占旗。
4. 脱离战斗后让弟弟在附近，使用绞盘。弟弟走到位后维持装置，玩家从服务门进入并打开内闩；也可走外侧绕路。移动、受击、超距等中断应保持退路。
5. 两人在横梁操作面就位后进行 3 秒移梁；测试中途取消及再次完成。确认通道可实际往返，不能仅看模型位置。
6. 到封存粮窖，观察油灯与悬片，尝试侧路观察和正面处理敌人。内室账板是独立新目标；原有两包熟食沿用旧领取记录。开启内闩、放下短梯并往返，检查同伴能否会合。
7. 工匠、识药的族人、守望者分别要求到旧物匣、旧药圃、旧号台附近实际观察，再返回交谈。纪念选择可留营地或故乡；故乡选项与守望者结尾等待真正胜利。陈列台先预览再确认，同一纪念物只能占一个位置。
8. 保存、退出整个进程、重新继续。检查灯、通路、搬梁结果、人物选择和陈列，同时核对装备 GUID、耐久、物资、敌军与原任务奖励。

## 需要真人记录的内容

- 首件至少 3 名未读设计的玩家；整轮至少 5 名玩家。分别记录迷路、误解、操作失败、路线、耗时、消耗及未完成原因。
- 对战斗可读性、后退手感、镜头反馈、动作接触、雨景、室内外声音和人物台词作判断。
- 比较工坊和粮窖的决策差异；检查纪念选择是否被理解为生活选择。
- 独立 Reviewer、Owner 最终签收，以及任务包要求的第二台实机验收。

这些记录保留原话和失败，不由脚本预填通过。性能未达标、缺样本和未完成的机器验证仍由开发报告单列，不能转成已通过的人工事项。
