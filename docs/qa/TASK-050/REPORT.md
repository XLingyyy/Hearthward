## 本次可执行范围

- `store`只接管弟弟背包已有的普通可堆叠物品，送至当前营地共享仓库。按实际入库记完成，不把旧货物记为新采集；无法返营或入库时保留物资。现有仓库无常规容量上限，不能用此场景证明“仓库只剩4份容量”的分趟要求。
- `nature_care`只接收唯一已知地块／栏舍ID，支持地块浇水、施肥、成熟收获以及栏舍投入饲料。任务卡先确认，弟弟执行五秒动作，Nature原有结算入口扣料／产出，回执按动作次数记账。未成熟、已做或缺料由领域状态拒绝，不由模型造物。
- `repair`可在手动任务卡选弟弟持有的明确EquipmentId；同类多件不随机选第一件。卡片显示所选实例耐久和按当前磨损计算的预计费用，提交时复核材料与实例。旧无ID目标仍只接受唯一同类实例。实例身份和耐久随schema8存档恢复。
- 已确认的规则按约束类型与物品替换同一槽位；`allow:物品`只解除后续禁用，`once:物品`仅对明确本次的任务跳过对应禁用，其他预算保留。记忆页一张确认卡列出执行中的任务、未确认候选和玩家规则，确认后统一取消；玩家陈述、事实、回执与货物保留。确认前后复核30米、任务ID、记忆修订和时间线。
- 三日交流按W计4320分钟。新进度及首次会合前保存的节点等到兄弟首次进入30米后起算；旧档缺计时字段则以载入W起算。同一安全营地、可交流、无战斗／对话占用时给一次短提醒，回营与存档状态按规则恢复。救援中断消耗性活动后须玩家明确继续。
