# 中世纪哥特主角建模要求

## 视觉基准

- 唯一参考图：`reference/主角-中世纪哥特-正面.png`
- 写实成年男性，深色中世纪哥特风格；保持参考图的脸型、黑色中长发和短胡须。
- 保留黑色旧化披风、深色长袍、链甲袖与裙甲、皮革肩甲/臂甲/护胫、腰带和金属扣件的层次。
- 保留低饱和黑、炭灰、旧铁和深棕皮革配色，以及克制的哥特纹样。
- 人体比例自然，双脚着地，朝前站立；避免底座、额外人物、额外肢体和夸张装饰。

## 首轮 Tripo 参数

- 输入：单张本地 PNG 参考图。
- 模型：`v3.1-20260211`。
- 面数上限：80,000。
- PBR 与纹理：开启，`detailed`，优先贴合原图。
- 朝向：`align_image`。
- 拓扑：请求 `quad`；按 Tripo 当前规则优先输出 FBX，便于 Unreal Engine 导入。

## Unreal Engine 交付边界

首轮输出目标是可由 Unreal Engine 内容浏览器直接导入的带材质网格。Tripo 单图建模不会自动保证：

- 已绑定 UE5 Manny/Quinn 兼容骨架；
- 披风、链甲、头发和刀鞘具有适合动画的拓扑或物理设置；
- 材质自动满足 UE 的 ORM 通道打包与命名规范；
- 单张正面图无法观察的背面细节完全符合设计预期。

若角色需要移动、战斗和披风物理，模型生成后仍需进行骨骼绑定、权重检查、动画重定向、碰撞/物理资产和材质整理。
