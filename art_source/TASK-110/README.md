# TASK-110 物品图像来源与实物对应

77 件物品使用 58 张独立透明 PNG，均为 1254×1254 RGBA。运行时资源位于 Resources/UI/Items；catalog.json 逐项记录物品、名称、图标键和文件。generation.json 保留生成提示、原始输出位置及两种鱼的修订来源。使用 OpenAI image_gen 生成。

统一美术约定：暖中性色写实材质、左上柔光、独立主体、透明背景；图中不包含文字、边框或数量。名称、等级、数量由游戏界面提供。

## 对应依据
- 石斧：TASK-028 当前生产石斧的石刃、绑扎和骨质柄轮廓。
- 短刃、长剑、长矛、战斧、弩、长弓、箭筒和箭：通过 UE 隔离预览读取当前角色实际使用的模型。预览脚本为 scripts/ui/render_item_references.py；模型截图已保留在 model-references；本机原始证据 E:/HearthwardQA/TASK-110/references-v3/frames。
- 当前武器同类不同等级使用相同模型；所检查短刃、长剑、长矛低高阶显示近似灰金属外观。因此同类等级共用图片，名称与属性继续区分等级。炉火短刃、稀有猎弓跟随其实际武器类别外形。
- 四种鱼：参照 art_source/TASK-051/animal_motion/视觉检查 的对应模型截图。鲫鱼与鳗鱼去除生成中多出的口须。
- 草药：对应无红色浆果的灌木叶片；移除旧图将草药表现成红色浆果的混淆。
- 木、石、矿、皮革与食材：按既有物品材质、用途及世界资源类别设计；石材、矿石、精炼矿、铁锭、钢锭独立表现。
- 服装、盾、镐、钓竿等目前没有随该物品切换的独立可见角色模型，图片按数据中的材质、用途和既有图像设计。不能据此声称这些物品已完成逐件三维外观核验。以后添加独立模型时，应以本目录对应图片一起校对。
- 药膏半份与整份使用同容器图像；物品名称和数量负责区分剩余份量。

## 渲染
物品使用 item.<id> 键，直接读取完整 PNG，不再放大旧图集的小切片。背包格与详情图保持正方形比例；文字和数量仍为实时 UI。旧图集为其他界面符号保留，本轮没有修改世界模型和存档格式。

高清物品 PNG 总计约 94.8 MiB。本轮没有生成额外 Shipping 包。
