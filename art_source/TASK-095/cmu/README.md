# Motion source

Source: [CMU Graphics Lab Motion Capture Database](https://mocap.cs.cmu.edu/), subject 113, clip 08 (lay down and get up).
BVH conversion: Bruce Hahne / cgspeed, mirrored by [una-dinosauria/cmu-mocap](https://github.com/una-dinosauria/cmu-mocap), data/113/113_08.bvh.

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

CMU permits use in commercial products; do not resell the raw motion data directly. Converted data follows the source terms. This project uses retargeted and edited animations, with the original clip retained for reproducible authoring.

Down and GetUp derive from this clip, mapped with GameFactory world_delta and registered cmu_bvh / ue5_mannequin anatomical profiles. Rescue is an authored kneeling/assistance performance using the retargeted standing and kneeling poses with hand constraints. Original Hero/Brother geometry and textures retain their separate provenance; this motion license does not establish rights to those assets.
