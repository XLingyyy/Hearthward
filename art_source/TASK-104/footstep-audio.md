## 分地表制作

每个变体有独立噪声、鞋跟与前掌接触时间、颗粒数量/位置、衰减和局部模态参数。鞋跟后约 42–70 ms 的前掌事件属于同一次落脚，不是第二个脚步触发。不是对同一个声音调音高来冒充多种地表。

- 草地 grass：较软的低频鞋底压实、两层宽叶片摩擦包络、稀疏干叶微碎裂；以沙沙声区别于砂粒。
- 泥地 dirt：压实土壤的中低频冲击、两簇位置随机的小砂粒碎响及短促鞋尖拖擦。
- 石面 stone：短而硬的鞋底接触、较亮的细碎冲击、低频脚步体积和短粗糙摩擦；不使用金属长鸣。
- 木板 wood：鞋底接触激发多个非整数倍、各自衰减的木板模态，叠加短纹理摩擦；比石面更有空腔感。
- 未知 unknown：独立的中性、偏柔和鞋跟/前掌与皮革鞋底摩擦，供未识别地面回退；不强行指定某种地表。

用户已批准本单合辑的听感方向；这些合成设计描述仍不等于场景中的触发/混音通过。最终场景音量、距离衰减、步态同步与辨识度仍需在 UE 中试听。

## 复现与校验

在仓库根目录执行（本次使用 CPython 3.12）：

```sh
python scripts/audio/generate_surface_footsteps.py
python scripts/audio/generate_surface_footsteps.py --check
```

第一条覆盖本单 15 个输出、清单与试听合辑；第二条只在内存重建并逐字节比对，不写文件。更改程序后必须重新生成，清单同时绑定程序自身 SHA-256。

`make_outputs()` 返回 `(outputs, review_bytes)`；`outputs` 是包含 15 个 WAV 文件名和 `PROVENANCE.json` 的 bytes 字典。`render(surface, variant)` 返回 PCM 整数列表与种子/接触时间元数据。可导入这些接口进行不依赖外部声音素材的工具测试。

本单 15 个运行时 WAV 通过 `.gitattributes` 的精确路径例外以普通 Git 二进制保存，避免正常检出或 CI 因未拉取 LFS 实体而缺音。试听合辑的存储方式以其精确路径属性为准。仓库其他 WAV 的通用 LFS 规则不因此改变。`--check` 要求真实 WAV 字节；LFS 指针本身不能证明可播放，禁止把指针内容当 WAV。针对历史/迁移检出的指针形式，工具测试可将 `make_outputs()` 生成的真实字节哈希和长度与指针的 oid/size 比对，并对内存 PCM 做波形检查；此时只证明指针与生成源一致，不宣称已验证远端 LFS 实体或 UE 播放。

## 数值验证

- 15 个文件 SHA-256 全部不同；各变体独立生成。
- 时长 0.213–0.301 秒；峰值 -6.305 至 -4.632 dBFS，保留至少 4.6 dB 余量。
- 整段 RMS -27.087 至 -22.136 dBFS。
- 所有文件削波样本数为 0，整数样本总和为 0（均值 DC 为 0）。
- 亚声频/DC 高通、平滑淡出和末尾 3 ms 精确静音；每段首尾均为 0，避免拼接边界突变。
- `--check` 验证时长、非静音能量、余量、DC、削波与边界，以及输出/清单/试听合辑精确复现。
- 数值检查不替代听觉验收，也不证明游戏中的触发与地表识别正确。
